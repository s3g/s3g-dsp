Sample Slicer

Sample Slicer is a four-break instrument in the Sample family, designed to pair with s3g Tracker or any MIDI source. It loads mono, stereo, or multichannel audio, divides each file into playable slices, maps those slices to consecutive notes, and keeps every source channel sample-aligned through pitch, reverse, looping, inserts, and mixing.

The bundle exposes two fixed-output instruments. Sample Slicer 2 has a stereo output and accepts mono or stereo files. Sample Slicer 16 has a 16-channel output, accepts files with one to sixteen channels, and preserves wider sources in channel order without folding or truncation.

Workflow

  1. Choose Sample Slicer 2 for mono/stereo production or Sample Slicer 16 for a source or destination wider than stereo. Set a REAPER track containing the 16-channel version to sixteen channels.
  2. Route the stereo version to a normal monitor path. For the 16-channel version, connect its fixed output to a compatible multichannel destination and monitor path before loading audio.
  3. Drop as many as four files onto the Overview waveforms or break cards. A multi-file drop fills successive slots.
  4. Select a break and choose equal or transient slicing. Adjust markers on Break Edit when the automatic result needs correction.
  5. Choose the lowest starting note and MIDI receive channel for the break, then press AUTO MAP. A fresh bank starts every break at MIDI note 48 / C2, with breaks 1–4 receiving on MIDI channels 1–4. Marker additions, deletions, re-slicing, and starting-note changes require a new Auto Map operation.
  6. Play the mapped notes from Tracker, a keyboard, or the Break Edit audition keyboard. Shape each break with its proportional envelope, slice properties, two inserts, mixer strip, and AUX send.
  7. Leave PROJECT AUDIO: EMBED enabled when the project should reopen without the original files, or select PATHS for smaller project state and keep the source files in a stable location.

Loading and Project Audio

Audio decoding and transient analysis run after a user-initiated load. Replacing or clearing a slot cancels stale work, so an older decode cannot overwrite the newer selection. Long filenames are shortened in the mixer while the complete path remains part of project state.

PROJECT AUDIO: EMBED stores decoded audio with the host project while preserving every source channel. A single instance can embed up to 1 GiB; if the bank exceeds that bound, the control reports PARTIAL and later slots use their stored paths. PATHS keeps state smaller but requires the original media to remain available.

Slicing and Mapping

Equal slicing divides the complete file into a chosen number of regions. Transient slicing derives one onset sequence from the source as a whole, then applies the same boundaries to every channel. Zero-crossing snap and the adjustable pre-transient offset help retain attacks without introducing unrelated channel timing.

START sets the lowest MIDI note used by a break, and the available slice count is 128 − START. The default start of 48 / C2 allows 80 slices on notes 48–127; start note 0 allows all 128 slices on notes 0–127. Equal slicing, transient slicing, and manual marker creation respect that ceiling. AUTO MAP always begins at the selected note and never moves it to make an oversized slice table fit. Reduce or re-slice first when an existing table is too large for a higher starting note.

Use START − and START + for semitone changes. Hold Shift for octave changes or Option to jump to the lowest or highest starting note that fits the current slice table.

Double-click a detailed waveform to add a marker, drag a marker to move it, and use the contextual delete action to remove it. Zoom changes the visible frame range without changing the slices. Moving an existing marker preserves a valid note map; structural edits clear the map so the new slice count cannot silently collide with another break.

Playback and Slice Behavior

Thirty-two playback voices share one clock per voice across every source channel. Velocity, proportional attack/decay/release, pitch, pan, reverse, looping, ping-pong, and choke behavior therefore remain synchronized for mono, stereo, discrete multichannel, and encoded source files.

Each selected slice has gain, pitch, pan, direction, launch mode, and choke controls. Pan applies to mono and stereo files; it is locked for wider sources so their channel order remains intact. The launch choices cover one-shot, gate, thru, loop, and ping-pong behavior.

Mixer, Inserts, and Break Bus

Each break owns level, stereo pan where applicable, three-band EQ with tunable mid frequency, mute, solo, audition, two serial inserts, and a post-fader AUX send. Active voices adopt mixer and insert edits on the next audio block without restarting the slice.

The Break Bus can link detection across all channels, adjacent pairs, or independent lanes. FIELD SAFE retains linked dynamics, snap, and linear tilt while bypassing nonlinear stages, allowing encoded or other phase-related multichannel material to keep its channel relationships.

Routing and State

  • Input: one CLAP note/MIDI port and file loading through the editor.
  • Sample Slicer 2 output: one fixed stereo port.
  • Sample Slicer 16 output: one fixed 16-channel port; unused channels remain silent.
  • State: break paths, optional embedded audio, slices, maps, envelopes, slice behavior, inserts, mixer, AUX, and output controls.

The 16-channel variant preserves source lanes in order and does not claim an ambisonic encoding. It can carry quad, octal, arbitrary discrete, or compatible encoded material when the surrounding routing is configured accordingly.
