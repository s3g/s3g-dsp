Ambisonic Decoders

Decoders turn an ACN/SN3D field into speaker, object, subwoofer, stereo, or headphone feeds. Match the decoder order to the encoded material and make its output bus the final spatial rendering stage.

Workflow

  1. Choose a decoder and insert it after the encoded source and any Ambisonic processing on a track wide enough for the incoming and rendered buses. Match its order and input format to the encoded material, then select its speaker layout, sub count, stereo pickup, or head model.
  2. Route its outputs to the matching physical speakers, stereo destination, or headphones.
  3. Refine orientation, weighting, and output level while the source is playing.

Speaker and Object Rendering

  • Ambi Decoder Speaker: decodes first-through-seventh-order material to built-in or custom speaker layouts.
  • Object, Adaptive, and Sub variants: focus the decode on object directions, adapt the rendering behavior, or derive low-frequency feeds while retaining the shared layout model.

Stereo and Headphone Monitoring

  • Ambi Decoder Stereo: rotation-aware virtual-speaker decode to a true stereo output bus.
  • Ambi Decoder Head: binaural headphone rendering with listener orientation and room controls.

Host Routing

In REAPER, set the track wide enough for the incoming order before inserting the decoder. Stereo and headphone variants expose a true two-channel output; enable Zero out unmapped output channels in the pin connector if REAPER passes higher track channels around the plugin.
