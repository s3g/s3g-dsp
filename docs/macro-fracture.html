Macro Fracture

s3g Macro Fracture gathers ten NIM-derived disruption and voice processors into one Mono, 8-channel, or 24-channel CLAP. The selected model changes the meaning of three contextual controls while REACT, MEMORY, mix, and the multichannel relationship system stay consistent.

The processor menu covers contact-like gating, sample and bit reduction, short-buffer rearrangement, two-input logic, amplitude voids, formant coloration, robot modulation, and three octave treatments. Model changes crossfade over 20 ms. Each change also begins from the preceding wet sample and releases that continuity correction smoothly, including when another model is selected before the first transition finishes. Every signal path is DC-blocked and bounded.

Workflow

  1. Insert the Mono, 8-channel, or 24-channel build on a matching REAPER track, configure the input pins, and begin at a conservative monitoring level.
  2. Route the result to the main speakers, a direct panner, or a stereo or quad fold-down, then begin playback. Another effect may precede that destination when its build matches the current bus width.
  3. Choose a PROCESSOR, set its three contextual controls, and use REACT to make transients push the treatment.
  4. Add MEMORY only when the processor should recur or smear into itself, then set MIX and OUT.
  5. On the multichannel builds, shape color and bias relationships across the lanes before automating the shared voice.

Versions and Routing

  • s3g Macro Fracture Mono: one input and output channel. LOGIC compares the input against a signal-relative carrier assist.
  • s3g Macro Fracture 8ch: eight independent processor states. LOGIC compares each lane against its next neighbor plus a low-level signal-relative carrier assist.
  • s3g Macro Fracture 24ch: twenty-four independent states and the same ring-neighbor LOGIC relationship.

The plugin preserves lane identity and does not mix or ambisonically encode the bus. In the multichannel LOGIC model, the last lane wraps around to the first, so the comparison forms a closed ring. The carrier assist has a stable lane-specific phase and follows the greater of the lane and neighbor levels. It keeps identical or strongly correlated material from collapsing to one static logic state, then decays with the signal rather than creating a free-running tone.

Shared Controls

ControlMeaning
PROCESSORSelects one of the ten fracture models. Changes use a 20 ms crossfade plus a smooth correction from the preceding wet sample, protecting both ordinary changes and rapid retargeting.
INPUTApplies gain before activity analysis and the selected model.
Context controlsThe next three labels change with the selected model. Their host parameter names remain Amount, Color, and Bias so automation and saved state stay stable.
REACTLets signal energy and transients increase processing amount and briefly brighten or accelerate the model.
MEMORYFeeds a bounded version of the model output back into its input. At zero, the shared NIM kernel receives the unrecirculated signal.
MIX / OUTSets the processed blend and final level.
PANICClears processor histories, short buffers, and recurrence without changing parameter values.

In Ambi Encoder Cartography, the same third contextual value is carried by the shared REL-page SKEW parameter. Its visible label follows the selected Fracture processor—for example Balance for Logic, Direction for Splice, and Character for Robot—and it acts as the processor's global third control there, not as an additional lane-slope control. This preserves Cartography's shared automation identities while exposing all three processor meanings.

These are the same shared kernels used by the corresponding NIM insert types. Macro Fracture adds oversampled stepping, transition continuity, reactive control, recurrence, wet/dry mixing, and lane relationships around them.

Relay, Logic, Void, and the octave detectors derive their working thresholds or offsets from slowly tracked signal level, so the same control setting remains useful across quieter and louder sources. Crush likewise normalizes its quantizer and dither to the tracked level; once both the input and held sample are silent it returns exact zero instead of leaving a dither or bias floor. Logic's assist also follows tracked level. These rules do not suppress intentional history: Splice may finish buffered material, Throat may retain a short resonant decay, and MEMORY may continue bounded recurrence.

Splice keeps segment position normalized, interpolates adjacent buffer samples, and returns toward the live input at both edges. Length and Direction are read only when a segment begins, so automation cannot teleport or reverse the current read halfway through it. Robot's Character morph uses continuous carrier shapes: negative values move from sine toward triangle, while positive values move toward a softly saturated square.

Multichannel Relationships

  • SPREAD distributes the contextual Color setting around the selected center lane.
  • DEVIATION adds repeatable lane-specific variation to Amount, Color, Bias, and a small amount of Memory.
  • SKEW creates a first-to-last-lane bias slope.
  • CENTER moves the neutral lane of the Color spread.
  • GLIDE smooths all relationship changes.

The relationship preview uses a bright marker for contextual Color and a darker marker for Bias. Relationship controls are omitted from the Mono build.

Memory and Safety

MEMORY uses a sub-unity, saturated recurrence path rather than exposing an unrestricted feedback gain. The processor also clamps internal excursions, removes output DC, rejects non-finite values, and applies a final soft bound. Processor selection retains separate model histories while the 20 ms crossfade and wet-sample correction protect the handoff; PANIC is the explicit way to clear those histories. The activity panel shows how strongly the result differs from the driven input.
