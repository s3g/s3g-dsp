Output Format Upscale 64

s3g Output Format Upscale 64 expands one named ordinary multichannel format into another without encoding an ambisonic field. Its primary workflow is a matrix whose input rows and output columns are generated directly from the two selected speaker formats.

The CLAP exposes one fixed 64-channel input and one fixed 64-channel output for stable host routing. The selected formats determine which lanes are active; every inactive output is cleared.

Workflow

  1. Set the host track and plugin pins to 64 channels, then choose the source format with IN FORMAT and the larger destination with OUT FORMAT in the right rail. Each selector opens a fitted two-column menu to the left of the rail.
  2. Choose AUTO MODE in the Formats toolbox for the routing tradition you want: coordinate matching, same-side repetition, crisscross, rotation, interleaving, nearest-speaker distribution, a weighted span, exhaustive tier filling, or M/S spreading. Choosing a mode applies its automatic matrix immediately. AUTO MAP beside that label reapplies the selected mode after manual edits; CLEAR starts an empty editable matrix.
  3. Use the title-strip view selector to switch among MATRIX, TIER RINGS, and AED FLAT. The two layout views show equal-size abstract speaker plans; click an input point to reveal only its destinations or an output point to reveal only its contributors. POP OUT inside the Layout surface detaches that live page and returns the main plug-in to the matrix so both can remain visible; DOCK closes the detached panel and restores Layout inside the plug-in.
  4. Press CLEAR for an empty matrix, then click or drag across the crosspoints for the speaker outputs that should pass audio. A single click selects an existing connection or adds an empty one; double-click or right-click sets that connection to zero.
  5. Select a cell and adjust DIST WEIGHT, or drag vertically inside a sufficiently large cell, for a partial connection. Choose ROW or COLUMN beside SHAPE, then use FLAT, CENTER, EDGES, or TAPER across that selected axis. In Auto Map, row shaping remains a global recipe applied to every input.
  6. In the Selected Crosspoint toolbox, choose ROW NORM, COL NORM, or the default DUAL LIMIT. Row and column power cannot both equal one in a rectangular matrix unless their dimensions happen to balance. For editable and ordinary Share maps, DUAL LIMIT therefore row-normalizes first, then attenuates only output columns whose coefficient power exceeds one.
  7. Read the coordinate policy directly on the matrix: input labels show role and AED, output columns show azimuth, and contiguous output elevations are bracketed as tiers. The selected-crosspoint inspector adds exact input/output AED and Cartesian XYZ values without requiring a separate speaker map.
  8. Press EDIT IN or EDIT OUT in the Formats toolbox header to copy that side to a Custom AED layout. Use COUNT and SELECT to change or choose channels, then use the full-length AZ, EL, and DST controls or numeric fields for exact coordinates. FRONT 3 and 3 × 3 TIERS provide useful starting arrays.
  9. If useful, use OUTPUT TREATMENT to add delay or decorrelation to the routed copies, smooth routing changes, and set the final plugin level. Verify destination channel order before routing to hardware.

Formats

The format library uses the same coordinate and channel-order policy as Layout Panner and Speaker Decoder. Presets include Mono, Stereo, LCR, Quad, Quad + overhead, 5.0, 6.0, 7.0, 5.0.2, 7.0.2, 5.0.4, 7.0.4, 9.0, 9.0.2, 9.0.4, 9.0.6, 7.0.6, 11.0.8, Octophonic and 12–64-channel rings, 16–64-channel double rings, Cube 8/17/41, LPAC 41, Dodeca 12, Icosahedron 20, Dome 24/25, SRST 25, Sphere 24, and Custom AED.

s3g AED uses +90° for listener-left and −90° for listener-right. Room-style preset order begins at the stereo-right position, proceeds clockwise around an elevation layer, and then appends higher layers. Custom layout channel order is exactly the order shown by the numbered nodes and SELECT control. A destination with fewer channels than the source is rejected safely; use an Output Autogain plugin for fold-down instead.

Controls

ControlMeaning

Matrix pointRows are inputs and columns are outputs. Click to select or add; drag across cells to paint full-weight connections. A vertical drag that remains inside a cell adjusts its magnitude, with upward motion increasing it and downward motion decreasing it. Double-click or right-click zeros the cell. Marker size follows magnitude; magenta marks a negative-polarity connection.
DIST WEIGHTSets the selected raw crosspoint magnitude from 0–100%. For a negative M/S connection it retains the generated polarity while changing that magnitude. The applied gain also depends on the selected normalization policy. Relative weights are preserved along the normalized or limited axis.
ROW / COLUMN SHAPESelects whether FLAT, CENTER, EDGES, and TAPER reshape the connected outputs in the selected input row or the contributing inputs in the selected output column. FLAT sets equal weights. CENTER produces a 50–100–50-style curve across ordered connections. EDGES reverses that curve. TAPER favors the selected crosspoint and reduces other weights according to AED angular distance, with a 25% floor. In Auto Map, ROW keeps its global automatic-row behavior; choosing COLUMN and a shape converts the visible map to an editable matrix.
ROW NORMNormalizes each nonempty input row independently: gij = wij / √Σow²io. Each distributed input has unit coefficient power, but several inputs converging on one output can give that column power greater than one.
COL NORMNormalizes each nonempty output column independently: gij = wij / √Σiw²ij. This is useful when many inputs feed one speaker, but individual row powers are no longer guaranteed to equal one.
DUAL LIMITThe default for new instances. For an editable matrix or an ordinary Share map, it first performs row normalization, then scales down only columns whose Σg² exceeds one. Automatic Keep retains its origin-gain policy before the same column limit. DUAL LIMIT never boosts a sparse column. This is an L2 coefficient-power limit for nominally independent inputs, not a peak limiter; correlated signals can still sum above full scale.
AUTO MODESelects and immediately applies Match, Same Side, Cross, Rotate, Interleave, Nearest, Span, Tier Fill, or M/S Spread. Candidate output columns in the ordinary modes are ranked first by current assignment count and then by the selected spatial rule, so an eligible unused column wins before a column is reused. When every elevation tier has room for every input, each input is routed once on every tier before extra copies are allocated. M/S Spread instead constructs a complete signed matrix across all output tiers.
AUTO MAPLocated beside AUTO MODE in the Formats toolbox. Reapplies the selected automatic mode. Editing any cell captures the current automatic map as an editable matrix before applying the change.
CLEAREnters Matrix mode with every crosspoint off.
EDIT IN / OUTLocated in the Formats toolbox header. Copies the chosen preset side to Custom AED and opens count, channel selection, azimuth, elevation, and distance controls. AED and derived XYZ are shown together; distance is clamped to 0.10–3.00.
VIEW SELECTORThe title strip contains only MATRIX, TIER RINGS, and AED FLAT. TIER RINGS derives each tier’s top-plan shape from speaker AED and distance, puts the lowest physical plane on the outer Tier 1 contour, scales higher contours inward without overlap, reserves an outer gutter for the cardinal-degree labels, and places a +90° zenith speaker at the center. AED FLAT switches to common azimuth/elevation dimensions for exact coordinate verification. Click an input or output point to change focus instead of drawing an overlapping all-routes line graph. POP OUT is local to the Layout surface; DOCK returns it to the plug-in.
G DELAYA single global maximum-delay amount, not a per-speaker setting. Each treated output receives a fixed, deterministic value between 35% and 100% of the amount. In editable Matrix mode every visible connection is treated.
G DECORA single global decorrelation intensity, not a per-speaker setting. The allpass coefficient varies deterministically by output so routed copies do not receive identical treatment.
SMOOTHTransition time for route gains and extension delay changes.

Output Treatment

The Output Treatment section is downstream of matrix weighting. G DELAY and G DECOR are global amounts; there is not a separate user control for each speaker. The DSP derives a repeatable variation for every output channel, so one global setting still produces different delay and allpass values around the destination array. These treatments change the timing and correlation of routed copies without changing their displayed distribution weights.

In AUTO MAP, the original anchor routes remain untreated while only added extension routes receive these processes. Once the matrix is edited, all visible crosspoints belong to the editable routed layer and therefore receive Delay and Decor. Set both global amounts to zero for a pure gain matrix.

SMOOTH controls how quickly route gains and delay changes move to new values, reducing clicks during edits. GAIN is the final trim after routing, normalization, delay, and decorrelation. It changes the entire plugin output and does not alter the relative balance shown in the matrix.

Auto Map Modes

ModeAutomatic routing rule
MatchKeeps each source at its closest matching role or AED position. In a sufficiently populated height array, that position is repeated on every elevation tier.
Same SideAdds destinations on the same left, center, or right side as each source.
CrossAdds destinations on the opposite side, reproducing the familiar crisscross stereo-to-quad convention.
RotateAdvances added destinations around the array by the stored rotation angle; the default is 90°.
InterleaveDistributes sources by channel index, useful for regular rings and repeated tier structures.
NearestChooses the closest unused output coordinates for each source.
SpanUses nearby outputs but gives closer positions greater pre-normalization weight according to the stored spread setting.
Tier FillRoutes every input onto every elevation tier even when a tier has fewer speakers than inputs. Sparse-tier destinations are shared as evenly as possible, then the mode adds balanced routes until every output column has been used.
M/S SpreadPairs mirrored input channels, derives Mid and Side, sends Mid toward centerline and elevated outputs, and increases signed Side toward lateral outputs. Its fixed 75% width gives a moderate spread; elevation progressively reduces Side. Centerline or unpaired inputs follow the Mid contour. Every output tier participates, and selecting a paired crosspoint shows the equivalent M/S equation.

Copies counts the anchor as one target: a value of 2 normally means one anchor plus one added destination per input, not two added destinations. The standard modes keep that base count but globally load-balance their added routes, so two sources cannot reuse an eligible destination while another eligible column remains unused. Tier coverage takes priority when every tier can support a unique result. Tier Fill is the explicit exhaustive alternative: it may exceed the base copy count, permits balanced sharing where a tier is sparse, reaches every tier from every input, and then touches every output column. M/S Spread is also exhaustive and does not use anchor or copy-count semantics; its signed matrix is the complete audible map.

Reading the Matrix

The matrix always places one-based input channels on the left and output channels across the top. Large formats reduce cell size and label frequency while preserving every crosspoint. Filled teal points are active and grow with connection weight. Selection is reported textually in the crosspoint inspector and footer; the grid does not add bright row, column, or cell highlighting.

Output elevation tiers are expressed as brackets over contiguous matrix columns, while channel roles and AED values remain attached to the axes. Selecting any crosspoint shows both endpoints as AED and XYZ in the inspector. This keeps routing, weighting, ordering, and coordinate verification in one visual language.

Layout Mapping

The Layout page is a spatial counterpart to the editable matrix. It borrows the economical speaker-node language of Meyer Sound Spacemap Go without adopting its panning engine: circles identify input lanes and square nodes identify physical output channels. It deliberately omits the complete connector-line graph, which becomes ambiguous as mappings overlap.

TIER RINGS is the default projection. Each side is an abstract, listener-centered overhead plan: front is 0°, listener-left is +90°, listener-right is −90°, and rear is ±180°. Within each physical height plane, node placement follows horizontal XYZ reconstructed from AED and distance, so a rectangle remains rectangular, a circle remains circular, and an irregular layout retains its outline. The lowest plane is the outermost contour and Tier 1; successively higher planes receive higher tier numbers and are scaled inward into separated envelopes. A speaker at elevation +90° occupies the exact center because its azimuth has no physical meaning.

AED FLAT switches both equal-size panels to the same equirectangular coordinate check. Following the speaker-plan convention, azimuth +90° is on the left, 0° is centered, and −90° is on the right; elevation runs vertically from −90° to +90°, with the same coordinate occupying the same relative position on either side. A dedicated coordinate gutter separates the degree scale from boundary speaker labels. Speaker labels are centered beneath their nodes so the point itself remains unobstructed. Tier ranges use line-and-bracket guides only; Cube 41, LPAC 41, and other broad planes have no filled highlight blocks.

In either projection, click an input circle to focus that matrix row: only its mapped output squares receive route colors. Click an output square to focus that column: only its contributing input circles receive route colors. Light gray means a primary anchor route, teal means an extension or copy route, magenta means negative gain, and dark gray means no route in the current focus. Point size follows the absolute applied gain.

Tier identity follows Cartesian speaker height, Z = sin(E) × distance, rather than assuming every speaker on a physical plane has the same spherical elevation. Tier numbers always rise with physical height. The legend reports exact elevation and channel count; a broad plane also reports its Z coordinate and minimum-to-maximum elevation range. In TIER RINGS that plane becomes one shape-preserving contour, with a direct zenith separated to the center when present; in AED FLAT it receives an unfilled bracket. This matters for geometries such as Cube 41: its top five speakers share the Z +1.00 face, while their actual elevations span approximately +57°…+90°.

POP OUT opens a utility panel containing the live Layout page and automatically restores the main plug-in to Matrix, allowing both views to be watched together or placed on separate displays. The detached panel remains tied to the plug-in’s GUI lifetime. DOCK hides the utility panel and restores the same Layout page inside the main window.

Large Arrays

The matrix always fits the complete active input-by-output grid; label reduction never removes a channel or crosspoint. As cells become smaller, the axes switch from every-channel role/AED text to collision-spaced channel indices. The first channel, last channel, and selected channel remain addressable, while small teal edge ticks identify the selected row and column without filling them.

Azimuth text is shown only while a cell is wide enough to contain it. Elevation brackets remain visible, but a tier name is omitted when it cannot fit inside its own bracket. Exact role, AED, XYZ, weight, and normalized gain are always available in the selected-crosspoint inspector. A 64 × 64 layout therefore remains a real 4096-point matrix rather than becoming a simplified visual proxy.

This version is deliberately deterministic: it does not extract ambience, classify content, or solve a decode/re-encode field. M/S Spread is a fixed algebraic matrix recipe, not ambience extraction. The matrix, signed weights, normalization policy, automatic row shape, and both custom coordinate arrays are stored in plugin state, so the audible result remains traceable to visible connections and recallable with the session. The simplified interface exposes the routing tradition through AUTO MODE; the more detailed recipe parameters remain published for host automation and backward compatibility.
