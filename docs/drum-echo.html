Drum Echo

Drum Echo is a stereo, transient-aware, three-head tape delay for individual percussion voices and complete drum buses. It can reinforce selected attacks, duck the existing echo while a new hit lands, and recover the tail between hits.

The interaction model takes broad cues from classic multi-head tape echoes and modern software such as Arturia Delay TAPE-201. Drum Echo uses original DSP and is not a circuit or product emulation.

This effect is currently a source-build preview included with S3G_BUILD_FUTURE_COMPONENTS.

Workflow

  1. Insert s3g Drum Echo after a drum instrument or stereo drum bus.
  2. Route the processed track to the main stereo output or a headphone monitor.
  3. Choose a HEADS pattern and a host-synchronized CLOCK division, or select FREE and set TIME.
  4. Set HIT SEND positive to emphasize attacks in the repeats, or negative to keep clicks and sticks out of the echo.
  5. Raise DUCK, then tune SENSE until each new hit briefly clears the wet path without erasing its tail.
  6. Finish with feedback, wear, flutter, tone, stereo spread, mix, and output trim.

Heads and Clock

The three playback heads are equally spaced at one, two, and three times the base delay. HEADS selects any single head, the three two-head pairs, or all heads. The rhythmic pattern therefore remains related when tape time or host tempo changes.

CLOCK provides Free, 1/32, 1/16 triplet, 1/16, 1/8 triplet, 1/8, 1/4 triplet, 1/4, 1/2, and one-bar bases. Host tempo is read from the CLAP transport; 120 BPM is used when the host does not publish tempo. Time changes glide like a moving tape mechanism rather than jumping discontinuously.

Drum Response

ControlDrum-specific behavior
Hit SendChanges only the detected attack written into the echo. Positive values make kicks, sticks, and rim attacks repeat more strongly; negative values favor bodies and tails.
SenseMoves the transient and duck detector threshold from strong bus hits toward quiet percussion detail.
DuckAttenuates the wet output while a fresh hit is present, then releases over roughly 150 ms. Delay memory and feedback continue underneath.
ToneSets repeat bandwidth. Darker values reduce cymbal accumulation and leave more room for new attacks.
SpreadPlaces heads left, center, and right while adding restrained stereo cross-feedback.

Tape Behavior

WEAR increases record and regeneration saturation while reducing feedback bandwidth. FLUT combines two slow tape-speed variations whose depth grows nonlinearly, so low values add movement without noticeably shifting the groove. Feedback is high-pass protected and soft-limited to keep low drum energy from producing DC buildup or unbounded regeneration.

Automation and State

All fourteen controls are automatable and saved in CLAP state. The effect reports a tail derived from the longest active head and feedback setting. It allocates delay memory during activation, not on the audio thread.

Limits

Drum Echo requires a two-channel input and output and does not accept MIDI. It provides tape-style saturation and speed variation, but no spring-reverb model or claim of hardware accuracy. At extremely slow tempos, the longest head is limited by the prepared twelve-second delay memory.
