Processor No Input Mixer

s3g Processor No Input Mixer 8ch is a zero-audio-input, fixed eight-output CLAP feedback instrument. Each lane has its own resonant body, formant path, four-band EQ, three serial nonlinear inserts, return memory, level, and meter. A signed 8-by-8 matrix couples the lanes into one playable electronic ecology.

The instrument is inspired by no-input mixing, resonant-object excitation, and David Tudor's compositional use of gain, filtering, phase, and feedback. It is a new clean-room DSP design, not a circuit reconstruction or an emulation of a particular historical instrument. See the project references for the surrounding Tudor and feedback-network sources.

Workflow

  1. Set a REAPER track to eight channels, then insert s3g Processor No Input Mixer 8ch. No audio pins or MIDI source are required.
  2. Choose one of the title-band factory presets, or click RANDOM for a bounded complete-network variation.
  3. Activation injects a deterministic startup packet into the otherwise oscillator-free network. Click NEW to reseed the current patch without changing its matrix or processors.
  4. Begin with the diagonal matrix cells. They control each lane's local regeneration.
  5. Add a few off-diagonal routes. Positive gains reinforce a destination; negative gains can inhibit, cancel, or frequency-pull it.
  6. Balance FDBK, COUPL, and PHASE before opening insert gain. These controls determine whether the network settles, beats, bursts, or moves toward its governor.
  7. Select a lane, tune BODY and LOSS, then shape it with EQ and the three insert slots.
  8. Use KILL for one lane or PANIC to ramp down and clear the complete network.

Presets and Randomization

The title-band PRESET menu contains eight complete starting states. Selecting one replaces the global network, all sixty-four matrix gains, eight bodies and EQs, and all twenty-four insert slots, then injects that preset's deterministic seed.

RANDOM generates a new deterministic seed and varies the complete matrix, bodies, EQ, distortion types, insert settings, phase, drift, formant, feedback, and coupling. It keeps the final limiter enabled, the ceiling at -1 dB, output trim conservative, diagonal regeneration present on every lane, and all generated values inside the DSP's bounded operating ranges. NEW changes only the excitation seed.

Feedback Matrix

The matrix reads source lanes across the columns and destination lanes down the rows. Every route is bipolar from -1.00 to +1.00. The signal takes at least one sample of return memory before re-entering the matrix, so the graph never forms an algebraic loop.

PHASE blends direct returns with short all-pass-bearing paths. DRIFT introduces slow component-like tolerance movement, and FORMANT blends in a normalized product of low- and high-passed body signals. These are part of the feedback behavior rather than post-effects.

Lanes and EQ

BODY moves a four-resonator bank through a different deterministic material variation on every lane. LOSS controls its decay. LEVEL affects only the lane's output audition, while MUTE removes it from the output and allows its internal ecology to continue. KILL clears that lane's body, filters, nonlinear memories, and returns.

The lane EQ contains low shelf, swept mid frequency and gain, and high shelf controls. It sits inside the loop before the inserts, so boosts and cuts alter both timbre and feedback stability.

Nonlinear Inserts

Each lane owns three independently selectable serial slots. Type changes use a short crossfade and the nonlinear cells can run at 1x, 2x, or 4x quality. The pedal names identify transfer-family inspiration rather than component-perfect branded emulation.

The shared GAIN, TONE, BIAS, and LEVEL controls are interpreted musically for the selected transfer family. BYPASS removes only the selected slot.

Containment

Per-lane RMS and peak observers drive a slow feedback governor only when loop energy becomes unsafe. Normal transients are not treated as compressor input. Optional DC blocking surrounds the feedback path, and eight independent ceiling limiters protect the final outputs. The monitor reports QUIET, STABLE, EDGE, or RUNAWAY.

PANIC ramps the outputs down, clears all feedback, resonator, filter, oversampling, and limiter memories, and rearms from silence. It does not automatically reseed; click NEW when a fresh excitation is wanted.

Automation and State

The plugin exposes 282 stable CLAP parameters: ten global controls, sixty-four signed matrix gains, eight direct controls for each lane, and six controls for each of the twenty-four insert slots. Factory presets and randomization resolve into this ordinary parameter state, so their complete results are stored in the project. The selected lane, slot, source, destination, and editor page are stored as well. Matrix gains and continuous lane controls are automatable; processing allocates no memory after activation.
