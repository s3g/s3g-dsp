Standalone Apps

s3g standalone apps make selected instruments available without a CLAP host. They reuse the same processor implementations as the plug-ins, while adding the audio-device, output-routing, MIDI-device, session, and diagnostic controls needed to run as independent macOS applications.

The apps are separate downloads. Installing an app does not install, update, or require the s3g-dsp CLAP collection.

Available Apps

s3g No Input Mixer

The standalone No Input Mixer embeds the same eight-lane feedback instrument as s3g Processor No Input Mixer 8. It adds direct Core Audio operation, Stereo Autogain, Quad Autogain, direct eight-channel output, selectable hardware-output banks, Safe Mute and persistent Panic controls, CoreMIDI source and feedback selection, portable gesture sessions, and realtime diagnostics.

Open the No Input Mixer Standalone guide for installation, first launch, output routing, MIDI, saved settings, and troubleshooting.

Shared DSP, Separate Application

The sound engine is documented once on the corresponding processor page. App guides concentrate on the parts that differ outside a host. This keeps the plug-in and app aligned when the shared DSP changes without asking app users to work through REAPER-specific setup.

Current Platform

The current pre-release app is an Apple-silicon-only arm64 build for macOS 15 or newer. It is not compiled for Intel Macs and is not a universal binary. See the individual app guide for its current release and Gatekeeper instructions.
