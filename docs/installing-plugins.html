Installing Pre-release Plugins

These notes are for installing a packaged macOS CLAP zip from a GitHub pre-release. Plugin names, parameters, saved states, and included plugins may change.

The supported target is macOS + REAPER.

Requirements

  • A macOS pre-release zip from the s3g-dsp GitHub releases page.
  • REAPER.

Download

Pre-release builds are attached to GitHub releases when available. If no zip is available, use the Building From Source page.

Install

Unzip the pre-release package and run Install s3g-dsp CLAPs.command. The installer places the products in the user CLAP plugin folder:

~/Library/Audio/Plug-Ins/CLAP/

Using the installer is important when updating an earlier pre-release: manually copying only replaces identical filenames and cannot retire a bundle whose name changed. To inspect the full transaction first, open Terminal in the unzipped package and run:

./Install\ s3g-dsp\ CLAPs.command --dry-run

A normal run preflights and copies all 90 canonical bundles. If those installed binaries are already current and only their filenames need migration, use:

./Install\ s3g-dsp\ CLAPs.command --canonicalize-only

The normal installer copies all 90 products under canonical family-first filenames, such as s3g_ambi_encoder_modal_16.clap, s3g_ambi_decoder_stereo.clap, and s3g_processor_fault_8ch.clap. These filenames match the collection's current host-browser families. The underlying CLAP IDs remain stable, so the filename cleanup does not create new plugin identities or intentionally break saved projects.

Known older filenames are checked against the package's legacy manifest and moved to ~/Library/Application Support/s3g-dsp/CLAP Backups/<timestamp-pid>/ when their bundle identity matches. They are not silently deleted. An identity mismatch is left in place and reported, and unrelated CLAP bundles—including bundles from other s3g projects—are not touched. The installer records package ownership in ~/Library/Application Support/s3g-dsp/clap-install-receipt.tsv. REAPER may need a plugin rescan after installation.

The package also includes a VOT Wavetables library and an Ambi Vox Demo Voicebank. Both can be stored anywhere. Load a wavetable WAV from Ambi VOT Encoder, or select the complete demo voicebank folder from the Ambi Vox Encoder PHRASE panel.

Current pre-release bundles are ad-hoc signed for bundle integrity but are not Apple notarized. macOS security policy may therefore require explicit approval for downloaded builds.

Included Groups

The current pre-release package installs 90 products. The groups below combine fixed-width variants so the inventory remains readable.

  • Multichannel Effects: Processor Delay, Processor Wave Geometry, Processor Spectral, Macro Delay, Macro Pitch, Macro Shred, Spectral Spray 2ch/8ch, Processor Buffer, Shard Scatter, Orbit Delay, and Cascade Taps.
  • Monitoring / Fold-down: MC to Stereo/Quad Autogain and Multichannel Meter.
  • Direct Panning: Layout, DBAP, LBAP, and VBAP panners.
  • Bus Mixing / Routing: Matrix Group 32/64, Mixer Node Bus 128, and Passthrough Test 24ch.
  • Speaker-array Utilities: Sub Crossover and Array HPF/Delay/Trim 16/26/32/64.
  • Ambisonics: grouped as Encoders, Decoders, Effects, and Utilities, including the Point/Cloud/Terrain/Path/Ray/Ray Bilocation/VOT/Vox/Wave Terrain/Wind/Water/Pyrosphere/Cryosphere/Insect/Modal/Pulsar/Neural Ecology/Stochastic/Wrangler encoder families, speaker and monitoring decoders, the Ambi Effect DJ Filter, Delay, Pitch, Gain, Resonance Print, Partial Trace, Response Trace, and Displacement, field effects, interchange formats, and visualization.
  • Instruments: Processor Fault, Processor Loop, Processor Multi Loop, Ambi Encoder VOT, Ambi Encoder Vox, Ambi Encoder Wave Terrain, Ambi Encoder Wind, Ambi Encoder Water, Ambi Encoder Pyrosphere, Ambi Encoder Cryosphere, Ambi Encoder Insect, Ambi Encoder Modal, Ambi Encoder Pulsar, Ambi Encoder Neural Ecology, Ambi Encoder Stochastic, Ambi Encoder Wrangler, and Processor Ambi Grain.

Processor is the shared host-search family for the package's more developed, self-contained effects and instruments. It does not mean that every member uses topology: some do, while others are organized around delay, buffer, loop, grain, or codec workflows. s3g Processor Ambi Grain stays in this group because its loaded-file granulation workflow is the stronger family relationship; its ambisonic-file requirement describes the source format.

REAPER Setup

After installing, open REAPER and rescan CLAP plugins if the new builds do not appear automatically. Search for s3g in the FX browser.

For multichannel sessions, set the track channel count before inserting the plugin.

For true stereo-output plugins on wide REAPER tracks, including s3g Output Autogain Stereo, s3g Ambi Decoder Stereo, and s3g Ambi Decoder Head, open REAPER's plugin pin connector and enable Zero out unmapped output channels if a following meter still shows channels above 2. These CLAP plugins expose stereo output buses, but REAPER can still pass unmapped track channels around the effect unless this option is enabled.

s3g Output Autogain Quad exposes a four-channel output bus ordered L, R, RB, LB. s3g Effect Shard Scatter, s3g Effect Orbit Delay, and s3g Effect Cascade Taps expose sixteen output channels, so set the REAPER track channel count and plugin pins before auditioning those processors.

s3g Processor Fault is a zero-audio-input instrument with a fixed eight-channel output. Set the REAPER track to eight channels before inserting it; no audio input routing is required. Its FREE mode needs no MIDI, while MIDI mode accepts note input from the track.

If your hardware has only two output channels, see Listening on a Stereo System for choosing between MC to Stereo Autogain and the Ambi Stereo or Head decoders.

For mix, route, pan, and monitoring tools, see Multichannel. For ambisonics-specific tools, see Ambisonics. Companion REAPER workflows are documented in the s3g-mc ambisonics guide.

Cleanup

If older pre-release plugins appear in REAPER, quit the host, run the packaged installer again, and rescan the user CLAP folder:

~/Library/Audio/Plug-Ins/CLAP/

Use the installer's --dry-run report before making manual changes. Recognized aliases are preserved in the timestamped backup reported by the installer. Unknown or identity-mismatched bundles are deliberately left alone and must be reviewed individually.
