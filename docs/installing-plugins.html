Install s3g-dsp CLAP Plugins

The packaged pre-release supports REAPER on Apple silicon Macs only. Plugin names, parameters, saved states, and the included set may change before a stable release.

Compatibility: the release archive contains arm64 binaries for M1, M2, M3, M4, or newer Apple silicon Macs. It does not contain Intel x86_64 or universal binaries. For this unnotarized pre-release, install while signed in to a macOS administrator account or have administrator credentials available for Gatekeeper approval.

The installer writes only to the current user's Library and does not use sudo.

Download

Download the macOS CLAP zip from the GitHub releases page, then unzip it. If a binary is not available, see Building From Source.

Gatekeeper Approval and Installation

  1. Quit REAPER.
  2. Double-click Install s3g-dsp CLAPs.command in the unzipped package.
  3. If macOS says Install s3g-dsp CLAPs.command cannot be opened because it is from an unidentified developer, click OK.
  4. Open System Settings > Privacy & Security, scroll down to Security, and find the message that the command was blocked.
  5. Click Open Anyway. Depending on the macOS version, the first button may be labeled Open. In the confirmation dialog, click Open and authenticate when macOS asks. This override is available for about one hour after the failed launch attempt.
  6. If macOS asks whether Terminal may access the downloaded package or Downloads folder, click Allow.
  7. Wait for Terminal to report that installation is complete. Do not start REAPER before the installer finishes.
  8. Start REAPER and rescan CLAP plugins if the new builds do not appear automatically.

Apple documents the same override in Open a Mac app from an unknown developer.

The installer places the plugins in:

~/Library/Audio/Plug-Ins/CLAP/

During upgrades, it also backs up recognized older filenames so REAPER does not list duplicate versions. Other CLAP products are left untouched.

The pre-release bundles are ad-hoc signed for bundle integrity but are not Apple notarized. After the user explicitly approves the installer, it verifies the identities of its s3g-dsp bundles and copies them without propagating the download quarantine attribute. It does not disable Gatekeeper or change global security settings.

Do not remove quarantine from the complete CLAP directory. A command such as sudo xattr -rd com.apple.quarantine ~/Library/Audio/Plug-Ins/CLAP also changes unrelated plug-ins and is broader than necessary. The current installer handles only the s3g-dsp bundles it installs and does not need sudo.

This first-launch workflow is unavoidable for the current ad-hoc-signed archive. A future distribution must use Developer ID signing and Apple notarization—preferably as a signed and notarized installer package—to pass Gatekeeper without the manual override.

Manual Installation

The packaged installer is preferred because manual copying cannot retire older aliases. If a manual installation is necessary, use Terminal so quarantine is omitted only from the selected release bundles:

mkdir -p "$HOME/Library/Audio/Plug-Ins/CLAP"
for bundle in /path/to/unzipped-package/*.clap; do
  ditto --noqtn "$bundle" \
    "$HOME/Library/Audio/Plug-Ins/CLAP/$(basename "$bundle")"
done

Replace /path/to/unzipped-package with the package location. Manual copying cannot remove older renamed bundles, so use the packaged installer if an upgrade creates duplicate entries.

REAPER Setup

Search for s3g in REAPER's FX browser. Set the track channel count before inserting a multichannel plugin. Processor No Input Mixer and Processor Fault require eight track channels but no audio input.

See Multichannel for routing and channel setup, Stereo Listening for two-channel monitoring, or Ambisonics for ambisonic workflows.

If a Plugin Does Not Appear

  • Confirm that its complete .clap bundle is in ~/Library/Audio/Plug-Ins/CLAP/.
  • Rescan CLAP plugins in REAPER, then restart the host.
  • If REAPER reports that Apple cannot check every plug-in for malicious software, quit REAPER and rerun the current packaged installer. It replaces only recognized s3g-dsp bundles without propagating their quarantine attribute.
  • If the installer itself remains blocked, repeat the Privacy & Security approval within one hour of trying to open it.
  • If an upgrade shows duplicate names, quit REAPER and rerun the packaged installer.
