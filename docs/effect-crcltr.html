Effect CRCLTR

s3g Effect CRCLTR is a stereo-input, stereo-output dual looper with controls corresponding to the CRCLTR v1.0.1 Gen/Oopsy firmware for Noise Engineering Versio hardware.

Use it to capture two related loops, shape their playback independently, and move between them with a manual or modulated equal-power crossfade.

Workflow

  1. Insert Effect CRCLTR on a stereo REAPER track and route the source to its left and right inputs.
  2. Route the stereo output to the main speakers or stereo monitor path, set Blend toward the source, and begin playback. Another effect may precede that destination when its build matches the stereo bus.
  3. Choose Loop 1, Both, or Loop 2 with Record Target.
  4. Set Record to RECORD and hold it for the desired capture time.
  5. Return Record to Idle to close the loop and restart its playhead.
  6. Use Xfade Type and Xfade to move between the two loop engines.
  7. Balance the live source and loop crossfade with Blend.

A record hold shorter than 100 ms is discarded without changing an existing loop. The first 100 ms is kept in a pre-roll buffer, so a valid hold retains its beginning.

Two Loop Engines

Loop 1: seamless

Loop 1 uses the first half of the captured audio. Hold Record for twice the intended loop duration. A 10 ms equal-power seam crossfade gives a maximum playback loop of about 16 seconds from the 32-second capture memory.

Loop 2: groove duck

Loop 2 uses the full captured duration. A raised-cosine 250 ms edge window ducks the start and end to suppress clicks and make the seam pulse. Its maximum loop duration is about 32 seconds.

Sample-Rate Behavior

Rates, timing constants, and recording behavior adapt to the session sample rate, so loop durations remain consistent across sample rates.

Host Interface and Project State

  • The macOS CLAP provides a resizable native editor with Output, Capture, Loops, and Crossfade panels. Hosts may still expose the same controls in a generic parameter view.
  • Project state stores control settings but not captured loop audio. Record new loops after reopening a project.
  • Record gestures shorter than 100 ms leave existing loops unchanged.
  • Sine and trapezoid crossfade rates map from 0.25x to 4x relative to Loop 1 timing.
