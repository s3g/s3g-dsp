Processor Fault

s3g Processor Fault is a zero-audio-input, eight-output CLAP instrument that turns a generated byte field, an arbitrary file, or the waveform ancestry of a PCM WAV into continuously changing audio. It combines raw-data scanning, stochastic breakpoint geometry, damaged codec models, protocol modulation, and a bounded pressure, wavefold, and resonant-feedback stage. It can run continuously or respond as a velocity-sensitive MIDI instrument.

Raw-data scanning reads bytes as a moving waveform, while stochastic breakpoint geometry connects selected values with evolving curves. The codec section then introduces prediction errors, quantization, missing blocks, or damaged reconstruction as sound-generating processes rather than as file-format emulation.

The native editor uses a wide 1356-by-720 layout. Field, codec, and protocol modulation occupy three parallel columns; patch controls, performance state, and the compact envelope editor remain in one lower strip. Hosts may reduce the responsive viewport and use its scroll access without rescaling control hit areas.

Workflow

  1. Set a REAPER track to eight channels and insert s3g Processor Fault.
  2. Choose a preset or begin with INIT. Use OPEN ANY to replace the generated field with any file. A recognized WAV opened from INIT selects WAVE TRACE.
  3. Use FREE for continuous sound, or select MIDI and play notes from the DAW.
  4. Set SCAN, GEOMETRY, CHAOS, and FOLD for the underlying motion.
  5. Choose a codec, then use RATE, BITS, CARRIER, and DAMAGE to break its continuity.
  6. Choose a protocol-modulation SOURCE and TARGET, then raise INDEX. Try LOCK when the modulator should inherit the codec's transmission clock.
  7. Raise DRIVE, SHRED, and RESONANCE to expose the byte-field contours.
  8. Choose a ROUTE and set SPREAD for the eight-channel distribution.

A useful first experiment is a low displayed codec update rate with high FOLD, followed by enough DRIVE and SHRED to turn the held vectors into pronounced curves.

Performance

FREE preserves Fault's continuous generator behavior and bypasses the amplitude envelope. MIDI makes the same field engine a monophonic, last-note-priority voice. Note-on retriggers the attack from the current envelope level, velocity controls voice level, and releasing the active note returns to the most recently held note. When no notes remain, the release runs to silence and the field freezes once the envelope becomes idle.

MIDI note 60 (C4) is the patch's reference pitch: it retains the current SCAN speed and stochastic period behavior. Notes above or below it change traversal and breakpoint timing by equal-tempered semitone ratios, so an octave doubles or halves both clocks. This is relative pitch control rather than a promise of conventional oscillator tuning; byte structure, codecs, geometry, and loaded material can all pull the audible result away from a stable fundamental.

ControlMeaning
AAttack time from 1 ms to 5 seconds.
DDecay time from 5 ms to 8 seconds.
SSustain level from silence to full level.
RRelease time from 5 ms to 12 seconds.

The envelope graph is directly editable. Drag the attack and release endpoints horizontally, the decay breakpoint in both axes, and the sustain breakpoint vertically. The dashed live-level trace and highlighted breakpoint follow the active MIDI envelope stage.

PLAY and STOP remain global: they fade and freeze either mode. Presets, RANDOM PATCH, and MUTATE shape the timbre but leave the selected performance mode and ADSR settings alone.

Byte Field and Geometry

The default source is a deterministic 65,536-byte virtual field. GEN FIELD captures the currently selected CODEC as a hidden generation profile, rolls a new seed, and builds data chosen to expose that codec's characteristic behavior. The source readout shows the captured profile in brackets. Changing CODEC afterward does not rewrite the field, so the same material can be compared across codecs; press GEN FIELD again to tailor a new field to the new selection.

The profiles use different data grammars rather than post-processing the same noise: differential and predictive modes receive continuous slopes with controlled innovations; companders receive quiet detail and sparse peaks; speech-like modes receive voiced, residual, and excitation structure; DISC receives repeated blocks and markers; SUBBAND receives separated slow and alternating detail; TRANSFORM receives sparse short-block spectra; MODEM receives symbol plateaus; FAX receives repeated scanlines; SIGMA 1-BIT receives slowly changing oversampled curves; APT and HF FAX receive sync, phasing, telemetry, and image regions; HELL receives doubled raster glyphs; MORSE and SPARK CW receive dot-dash keying fields; BAUDOT RTTY receives start/data/stop frames; and SSTV receives sync, porch, separator, and color scanlines. For an arbitrary file, OPEN ANY reads from byte zero and maps every byte to an unsigned 8-bit bipolar sample.

With Decode WAVE data into eight lanes enabled in the open dialog, Fault parses RIFF chunks, jumps to the actual data chunk, and decodes integer PCM at 8, 16, 24, or 32 bits or floating-point PCM at 32 or 64 bits. It applies bounded gain recovery, remaps every source frame into eight related lanes, and requantizes those lanes into the byte field. Mono becomes eight short-offset traces; stereo becomes four related pairs; sources with eight or more channels retain eight native lanes. This preserves contour, rhythm, and some pitch identity without retaining a recoverable clean signal. Disable the option to include the WAV header and all other bytes in the older literal-byte treatment.

Raw files and the prepared eight-lane field are limited to 64 MiB. Longer sources show PARTIAL in the source readout. Internally, a shorter or irregularly sized source repeats far enough to form a power-of-two scan ring. The codec BITS control requantizes the field again later in the chain.

ControlMeaning
SCANSets traversal speed. Raw and generated fields report bytes per second. A prepared WAV reports a speed multiplier; 0.50 is the source's native frame rate and the full range extends from 1/256x to 256x.
TEXTUREChanges local smoothing and the blend among nearby bytes, structured regions, and metadata-like impulses.
GEOMETRYMorphs direct byte reading toward stochastic breakpoint segments and longer sample-to-sample connection curves.
CHAOSIncreases amplitude and period variation, octave-scale duration changes, irregular interpolation, and occasional rests.

EVOLVE is free-running rather than transport-synchronized. It changes regional content without replacing the whole field, so a patch can retain its identity while its local byte relationships drift.

Codec Damage

The codec section treats the generated or file-derived signal as material for destructive encoding. These modes are synthesis models, not interoperable media codecs. Their design sources are collected in the Codec references.

  • PCM applies direct bit quantization.
  • DELTA quantizes the difference from a running predictor.
  • ADPCM quantizes prediction error with a multiplicatively adapted step: large codes expand it quickly and small codes contract it slowly.
  • MU-LAW and A-LAW encode and decode eight-bit G.711-style sign, segment, and mantissa codewords. BITS removes low codeword planes below eight bits, while DAMAGE flips code bits.
  • CELP uses damaged pitch, gain, and codebook behavior. Missing packets replay pitch-synchronous history with progressive attenuation, followed by a short recovery crossfade. It is not a G.729 encoder, decoder, or bitstream implementation.
  • DISC introduces block errors whose duration selects the response: short gaps are interpolated with a 32-sample lookahead, medium gaps repeat or extrapolate fading history, and long gaps decay toward mute. It does not implement CD or DVD framing, modulation, or error correction.
  • CVSD tracks the signal with a one-bit adaptive slope. Three identical decisions expand the step; alternating decisions contract it; bit errors and a clock-relative reconstruction filter expose failure.
  • SUBBAND uses a downsampled two-band Haar quadrature-mirror bank with independently damaged adaptive quantizers for its low and high bands.
  • LPC replaces increasing amounts of prediction residual with pulse and noise excitation through an adaptive all-pole model.
  • TRANSFORM performs 32-sample DCT blocks with a damaged scale factor, frequency-weighted coefficient bit allocation, missing blocks, and coefficient-bit upsets.
  • PREDICT uses a second-order predictor with quantized residuals, missing corrections, and occasional residual upsets.
  • MODEM maps amplitude into damaged FSK-like symbols and carrier tones.
  • FAX maps level and slope into fixed QPSK, eight-QAM, or sixteen-QAM constellations, then exposes raised-cosine symbol transitions, training sequences, equalizer lag, and phase slips.
  • SIGMA 1-BIT uses a first-order integrated error-feedback loop followed by a bit-clock-relative reconstruction filter.
  • HYBRID combines a predictive base layer with a correction layer that can thin, vanish, or invert.
  • APT treats the signal as weather-satellite image brightness and amplitude-modulates a 2400 Hz subcarrier. Its 2080-word composite line carries paired image regions, telemetry wedges, minute markers, a seven-cycle 1040 Hz sync train, and a seven-pulse 832 Hz sync train. DAMAGE adds word errors, stale video, line slips, fading, carrier phase jumps, and receiver noise. It models the Automatic Picture Transmission sound and line grammar, not an interoperable RF transmission.
  • HF FAX scans brightness as frequency between the historical 1500 Hz black and 2300 Hz white limits around 1900 Hz. Each line begins with phasing and start bars; DAMAGE introduces wrong pixels, black dropouts, line slant, flutter, and phase slips.
  • HELL is a Feld-Hellschreiber-style 5-by-7 raster teleprinter with doubled vertical pixels and keyed 900 Hz ink. Clock mismatch and DAMAGE smear, repeat, drop, or invert raster cells.
  • MORSE converts the field into International Morse letters, preserving one-unit dots and intra-element gaps, three-unit dashes and character gaps, and a keyed 700 Hz tone. DAMAGE drops elements and adds chirp and key-edge roughness.
  • SPARK CW uses the same Morse timing but replaces the clean continuous-wave tone with damped, chirping, harmonic, noise-rich spark bursts.
  • BAUDOT RTTY sends ITA2-style five-bit letters with a start bit and stop interval as 170 Hz-shift FSK around 1700 Hz. It includes letters/figures shifts; DAMAGE flips data and shift decisions.
  • SSTV uses a slow-scan-television-style line: 1200 Hz sync, 1500 Hz porch and separators, then three 320-pixel color scans mapped from 1500 to 2300 Hz. DAMAGE causes false sync, frequency errors, and horizontal line slips.
ControlMeaning
RATESets the effective codec update rate. Most modes use it as a pre-encoding sample-and-hold; the transmission modes use it as a bit, symbol, raster-cell, Morse-element, or video-word clock. For APT, 4160 Hz gives the historical half-second composite line. Moving the control right lowers the displayed rate, reaching below 3 Hz at 48 kHz.
BITSSets an integer depth from 2 to 16 bits. In one-bit and carrier models it instead biases state count, tracking resolution, or reconstruction detail.
CARRIERTransposes carrier and image-tone frequencies by ±24 semitones while preserving each protocol's nominal center. The readout shows the resulting center frequency for carrier modes; double-click restores the historical or conventional center.
DAMAGERaises mode-specific prediction error, packet loss, stale blocks, coefficient removal, bit errors, phase slips, or correction-layer failure.

Protocol Modulation

Protocol modulation adds a second operator to the codec. It is a distant cousin of FM synthesis: one process acts on another, but the operator is not limited to a sinusoid and its destination is not limited to oscillator frequency. Raster sync, telegraph keying, framed bits, image scanlines, field data, and the codec's own output can become control signals. This makes the historically functional parts of a transmission system available as timbre structure.

The tonal sources are SINE, TRIANGLE, and stepped NOISE. FIELD follows the current byte-field signal; SYNC and GATE supply narrow and square pulses. APT, HF FAX, HELL, MORSE, SPARK CW, BAUDOT RTTY, and SSTV reuse simplified line, raster, keying, framing, and scan grammars as modulation shapes. FEEDBACK derives a bounded operator from the codec's recent output, turning the carrier/modulator distinction into a recursive loop.

ControlMeaning
SOURCESelects the second operator. OFF preserves earlier patches and bypasses modulation.
TARGETCARRIER bends the whole transmission center by up to two octaves. DEVIATION expands and contracts distances around the protocol's nominal center. CLOCK warps codec, bit, raster, and scan timing. DATA writes the operator into the pre-codec signal. DAMAGE turns it into a moving error probability.
RATESets the free-running operator rate from 0.05 Hz to 8 kHz.
RATIOMultiplies the free or locked base rate from 0.125× to 16×, providing the carrier-to-modulator-ratio role familiar from FM without requiring harmonic ratios.
INDEXSets modulation depth. At zero the selected source remains inaudible; increasing it moves farther into sidebands, clock fracture, data overwrite, or error bursts according to the target.
CLOCKFREE uses the displayed rate. LOCK derives a protocol-appropriate rate from the active codec clock or nominal carrier, so line, symbol, and raster relationships follow changes to codec RATE.
FEEDBACKRecirculates the preceding operator state. With the FEEDBACK source it controls a bounded codec-output loop; with other sources it smears clean periodicity toward recursive, unstable-looking contours.

Protocol sources are structural appropriations, not interoperable encoders. Their sync regions and alphabets are intentionally treated as compositional objects: once routed to carrier, deviation, clock, data, or damage, the protocol becomes an audible genealogy rather than a message-delivery system.

Integrated Nonlinear Stage

The shaping stage follows the codec so held steps and prediction errors become wave geometry rather than remaining quiet digital artifacts.

  • DRIVE raises level into pressure and saturation.
  • SHRED moves the nonlinear path toward stronger folding and edge generation.
  • RESONANCE raises a bounded internal feedback loop. Its tuning follows a smoothed spectral-center estimate of the generated material, while TEXTURE and CHAOS bias its color and response.
  • OUTPUT sets the final trim after internal calibration.

Feed-forward calibration and a slow, bounded level correction reduce large loudness jumps among codec and shaping settings. They do not normalize away transient or spectral differences. The final path removes DC and limits output to finite sample bounds.

Eight-Channel Routing

ROUTE changes how each output lane addresses the byte field:

  • PARALLEL keeps lanes near a shared read path.
  • DEINTERLEAVE distributes adjacent field data across eight lane-strided reads. For a prepared WAV, it follows the eight derived waveform lanes directly.
  • PLANES offsets lanes into separate field regions.
  • SHUFFLED uses repeatable hashed read addresses.
  • DIVERGENT gives lanes different strides and long-term trajectories.

SPREAD operates on the mean plus each channel's residual. At zero, all lanes collapse toward the instantaneous eight-channel mean. At one, their full differences remain. Bounded energy compensation prevents spread changes from acting mainly as gain changes.

The display shows eight recent output waveforms. Each trace scales itself to reveal shape and is therefore not an absolute level meter; use the peak readout or a following Multichannel Meter for level comparison.

Presets and Patch Actions

The factory bank now treats protocol modulation as part of the patch rather than an optional afterthought. INIT remains neutral with modulation off; every other factory preset selects an active source, target, ratio, index, and feedback relationship. Editing a sound control changes the menu state to CUSTOM.

WAVE TRACEThe loaded waveform feeds itself back into the data path at a restrained index.
  • PLAY resumes the field from its frozen position with a 20 ms fade-in.
  • STOP fades to silence over 20 ms, then freezes the synthesis engine without resetting it.
  • OPEN ANY loads any file as a byte field. Its enabled WAV option skips the container header and prepares eight lossy waveform-derived lanes; disabling the option uses every file byte literally.
  • GEN FIELD leaves file mode, captures the selected codec as the field profile, and creates new codec-oriented source data while retaining the remaining control settings.
  • RANDOM PATCH creates a new bounded patch across the field, codec, protocol-modulation, shaping, and routing sections.
  • MUTATE makes smaller changes around the current patch and usually preserves its seed and codec family.
  • UNDO restores the state before the most recent preset, source, field, randomize, or mutate action.

Preset, source, field, codec, bit-depth, and routing changes crossfade instead of resetting abruptly. The automatable Run parameter mirrors the PLAY and STOP buttons. REAPER project state stores the transport state, performance mode, ADSR settings, complete patch, field seed, captured generation profile, and external source path; held notes and source bytes are not embedded. If the file is unavailable on recall, Fault falls back to the generated field and shows the missing source in its header.
