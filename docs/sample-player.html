Sample Player

Sample Player 2 is the stereo one-shot and loop instrument in the Sample family. It accepts mono or stereo files and produces stereo output. Sample Player 16 accepts one to sixteen source channels and preserves them in order on a fixed 16-channel output.

Workflow

  1. Choose Sample Player 2 for mono/stereo work or Sample Player 16 when the source or destination is wider than stereo.
  2. Route its fixed output to the intended speakers or monitor path before loading audio.
  3. Press LOAD SAMPLE or drop an audio file on the waveform.
  4. On load, Start, the derived End, Loop Start, and Loop End default to safe zero crossings near the file boundaries.
  5. Set MIDI Receive to Omni or one MIDI channel. Omni preserves the original all-channel response and remains the default.
  6. Set Root Note, Tune, and Fine Tune for chromatic MIDI playback, then choose Rate or Stretch pitch mode. Choose Poly, Mono, or Legato voice handling; Glide applies to Legato pitch changes.
  7. Leave Tempo Sync at Free for the original timing. To follow the host, enter the sample's source BPM and select Host.
  8. Drag the labeled Start, End, Loop Start, and Loop End handles on the waveform, or use their sliders for exact normalized values. Scroll over the waveform to zoom, Shift-scroll to pan, and double-click open waveform space to fit the complete file.
  9. Select Forward, Forward Loop, Reverse, Reverse Loop, Forward Ping-Pong, or Reverse Ping-Pong. Loop points are clipped inside Start/Length.
  10. Raise Loop Crossfade to overlap the outgoing and incoming sides of a forward or reverse wrap. This remains useful even when both loop points sit on zero crossings.
  11. Choose Trigger and Retrigger behavior, then shape the result with the resonant multimode filter and proportional Attack, Decay, Sustain, and Release. The compact upper-right Output / MIDI panel begins with Out, followed by stereo Pan where available, MIDI Receive, and Velocity. Out and Pan operate on the final summed output, so they affect notes already in progress. Press KILL ALL whenever every active voice or latched loop must stop immediately.

Playback Modes

ModeBehavior
ForwardPlays once from Start to the end of Length.
Forward LoopPlays forward, then wraps from Loop End to Loop Start until note release.
ReversePlays the Start/Length window once from its end toward Start.
Reverse LoopPlays backward, then wraps from Loop Start to Loop End until note release.
Forward Ping-PongLaunches forward, then alternates direction at Loop End and Loop Start without a wrap.
Reverse Ping-PongLaunches backward, then alternates direction at Loop Start and Loop End without a wrap.

Poly mode gives every MIDI note an independent voice. Mono mode keeps one voice and restarts the sample for a new note. Legato also keeps one voice, but connected notes preserve the current playhead and envelope while pitch moves to the new note; Glide sets that transition from 0 to 2000 ms. When the current legato note is released, the most recently held note takes over when the selected Trigger behavior responds to note-off.

Pitch follows the distance from Root Note plus Tune and Fine Tune. Tune and Fine Tune retarget every active voice through a 10 ms smoothing transition, making their automation safe for notes already in progress. Root Note remains a trigger-time keyboard mapping. Rate mode uses conventional sampler playback, so higher notes finish sooner and lower notes finish later. Stretch mode changes pitch with overlapped grain readers while maintaining an independent transport clock.

Tempo Sync defaults to Free and therefore preserves the original playback behavior. Host mode compares the entered Sample BPM with the host tempo. In Rate mode that tempo ratio changes playback speed and pitch together; in Stretch mode it changes Start/Length and loop duration while preserving the pitch selected from MIDI, Root Note, Tune, and Fine Tune. If the host does not provide tempo, playback falls back safely to the entered Sample BPM ratio of 1:1.

Trigger and Retrigger

ControlBehavior
Trigger: AutoCompatibility default. Forward and Reverse ignore note-off; all loop modes release from note-off.
Trigger: GateEvery playback mode enters Release on note-off.
Trigger: One ShotNote-off is ignored. Non-looping modes finish once; loop modes continue until choked, replaced, or stopped by the host.
Trigger: ToggleA note starts playback; another press of the same key enters Release. Note-off is ignored.
Retrigger: LayerCompatibility default. Repeated notes may create additional voices in Poly mode.
Retrigger: RestartA repeated key replaces its matching active voice and starts from the selected boundary.
Retrigger: IgnoreA repeated key is ignored while its matching voice remains active.

Attack, Decay, and Release are percentages of the audible Start/Length duration; their combined value cannot exceed 100%. That duration follows playback rate in Rate mode and remains locked to the original sample timeline in Stretch mode. Sustain remains an amplitude percentage. Sustain changes reach held voices through a 10 ms smoothing transition. Release is recalculated for held voices until note-off or another action begins the Release stage; a release already in progress keeps its established duration.

With the default Auto trigger, Forward and Reverse are true one-shots: note-off does not truncate them, and Release is placed at the end of the selected sample window. All four loop modes sustain until note-off, then enter their proportional Release stage. One shared clock drives every channel in a voice so wide files remain sample-aligned through tempo sync, pitch changes, envelope stages, crossfades, and direction changes. Every active voice has its own waveform cursor labeled with its MIDI note number; voices are never averaged into one display position. Double-clicking a boundary slider restores its sample-aware safe default.

Waveform Editing and Filter

The waveform labels S, E, LS, and LE are direct handles. Start and End use the upper half of the display; Loop Start and Loop End use the lower half, so coincident default boundaries remain individually selectable. Zoom changes only the view and never changes playback positions.

Loop Crossfade is a percentage of the resolved loop span and is bounded so a playable loop body remains. It applies to Forward Loop and Reverse Loop; ping-pong modes reverse continuously at their endpoints and do not wrap. Loop Start, Loop End, and Loop Crossfade changes update active loop voices through a 5 ms click-safe transition. Start and Length remain fixed for each triggered voice.

The filter offers Off, Low Pass, Band Pass, High Pass, and Notch types. Cutoff is frequency-scaled from 20 Hz to 20 kHz, Resonance raises the response around cutoff, and bipolar Env Amount moves cutoff by as much as six octaves from the proportional amplitude envelope. Off is the compatibility default for restored projects.

Routing and State

  • Input: one CLAP note/MIDI port and file loading through the editor.
  • MIDI Receive: Omni by default, or Channel 1 through Channel 16. The filter applies equally to the stereo and 16-channel versions.
  • Sample Player 2 output: one fixed stereo port; mono is presented on both stereo lanes.
  • Sample Player 16 output: one fixed 16-channel port; unused lanes remain silent.
  • Pan is exclusive to Sample Player 2, where it places mono sources across stereo or balances a stereo source.
  • Sample Player 16 does not expose Pan. Every source lane maps directly to its matching output lane without stereo balancing or mono duplication; unused output lanes remain silent.
  • KILL ALL is a momentary, unsaved panic action. It clears every active voice and held-note state without unloading the sample or changing any controls; the next note starts normally.
  • EMBED IN STATE stores decoded audio with the project by default; the source path is also retained.
