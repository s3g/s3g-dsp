Sample Doubles

Sample Doubles 2 is a stereo instrument for cutting between two copies of one recording. The copies are independent read heads over the same mono or stereo source: Deck A establishes the main timeline, while Deck B can be synchronized at a musical offset, nudged in discrete steps, or allowed to drift gradually. A turntable-style crossfader and gated MIDI punches turn that relationship into a playable instrument.

Workflow

  1. Press LOAD SAMPLE or drop a mono or stereo audio file on the waveform. Leave EMBED ON enabled for portable project state, or choose EMBED OFF to store only its location.
  2. Route its fixed stereo output to the intended speakers or monitor path.
  3. After loading, inspect the BPM readout. A confident, unambiguous estimate is applied automatically; a less certain result is shown as a suggestion. Use 1/2, AUTO, or x2 to resolve octave choices, or edit SAMPLE BPM directly. This source tempo defines beat distances inside the file; it does not force the instrument to follow host tempo.
  4. Set SPEED. Its default of -7 semitones slows pitch and duration together, like changing turntable or tape speed.
  5. Drag the waveform's S and E handles to select a region. Choose ON from the LOOP menu when the two copies should remain inside it.
  6. Press RESTART. Deck A starts at S and Deck B starts at Deck A plus B OFFSET, measured in source beats.
  7. Set A LEVEL and B LEVEL, then move the crossfader between them. The deck levels are smoothed before the crossfade; OUT remains the post-crossfade master. XFADE CURVE provides CUT, SHARP, and equal-power BLEND.
  8. Use SYNC to restore the selected offset, STEP - and STEP + for discrete moves, or B LIVE PHASE for an immediate continuous nudge. A P/P and B P/P pause individual decks when LINK is off. Hold DRAG A or DRAG B to load that platter; release it for a smooth motor recovery.
  9. Sequence the command notes from s3g Tracker. The complete mapping is published through the CLAP note-name extension, so supporting hosts can display the commands by name.

Performance Model

The University of Houston's DJ Screw archive describes the defining gestures as a deep slowdown combined with manually repeated words, phrases, and beats. Doubles keeps those roles separate: Speed establishes the shared slowed world, while two copies, offsets, punches, and the crossfader create the chops. It deliberately omits a dub-print recorder because the performance can be captured by the host and the desired pitch is already part of varispeed playback.

The phase controls extend the two-copy idea in another direction. Steve Reich's description of Piano Phase begins with identical repeated patterns in unison, lets one move gradually ahead, and eventually returns them to unison. Deck B Drift realizes the continuous version of that process; Phase Step and Sync make its intermediate positions addressable from a tracker pattern.

Deck Timing

SPEED is authentic varispeed: pitch and duration remain coupled. Both decks use this common rate. B DRIFT adds a fine speed difference to Deck B only, from -100 to +100 cents. Very small values create a slowly changing relationship; larger values move through alignments quickly.

B OFFSET is stored in beats but does not teleport Deck B whenever its slider moves. Press Sync or Restart to apply it. B LIVE PHASE is deliberately separate: moving it shifts Deck B immediately and precisely by its change in source beats. MIDI notes 48–60 select a signed stored offset and synchronize Deck B immediately. Phase Step moves the existing Deck B playhead backward or forward without changing either control.

Phase Step, Loop, Crossfader Curve, MIDI Receive, and Link are categorical or toggle settings. Speed, Sample BPM, Start, End, output level, both deck levels, Deck B Offset, Deck B Drift, Deck B Live Phase, and the crossfader remain continuous controls.

With Loop enabled, synchronization, offsets, drift, live phase, and phase steps wrap inside the selected S–E region. Without Loop, each deck stops when it reaches E. Stop silences both positions; Play resumes them, while Restart returns to the beginning and reapplies the offset. Link is enabled by default so either deck Play/Pause button operates both decks; disable it to stop and resume the two copies independently.

Drag is momentary rather than a saved speed setting. While held, that deck decelerates toward a heavily loaded platter; on release its motor eases back to the shared varispeed. Mouse release, MIDI note-off, editor close, and transport reset all release the gesture.

A practical Tracker layout uses one sparse lane for Restart, Sync, and offset selection, one lane for Punch A, and one for Punch B. Add Drag or independent deck-toggle notes where a platter gesture or one-sided pause belongs. These are ordinary notes, so Tracker's microtime, delay, repeat, ratchet, flam, stutter, probability, note length, and per-step volume can shape the performance directly. With the Cut curve, Tracker's normal note velocity is already deep enough to cross the narrow center transition; full volume lands completely on the punched deck.

The stepped and gradual settings let identical repeating material begin together, separate through a small rate difference, pass through intermediate relationships, and reunite. Doubles keeps that process performable by adding explicit Sync and Phase Step commands alongside the continuous B Drift control.

Routing and State

  • Input: one CLAP note/MIDI command port and file loading through the editor.
  • Output: one fixed stereo port. Mono files are presented on both lanes; stereo channel order is preserved.
  • MIDI Receive: Omni by default, or Channel 1 through Channel 16.
  • State: all sixteen parameters, source path, embed choice, and optionally as much as 1 GiB of decoded mono or stereo audio. Version-one twelve-parameter projects load with neutral deck levels, Link on, and zero live phase.
  • BPM analysis runs only on the sample-loader worker. Project recall restores the saved source BPM exactly and does not re-analyze or overwrite it.
  • The audio engine keeps one immutable source asset and two positions; it does not duplicate the decoded audio in memory and does not record a dub print.
