Sample Doubles

Sample Doubles 2 is a stereo instrument with two independently positioned read heads over one mono or stereo recording. Deck A and Deck B share the source while retaining separate positions, levels, cues, and transport states. You can synchronize them, place them at a beat offset, move them in discrete steps, or let their timing separate gradually, then switch or blend between them with the crossfader.

Workflow

  1. Press LOAD SAMPLE or drop a mono or stereo audio file on the waveform. Leave EMBED ON enabled for portable project state, or choose EMBED OFF to store only its location.
  2. Route its fixed stereo output to the intended speakers or monitor path.
  3. After loading, inspect the BPM readout. A confident, unambiguous estimate is applied automatically; a less certain result is shown as a suggestion. Use 1/2, AUTO, or x2 to resolve octave choices, or edit SAMPLE BPM directly. After a manual BPM edit, AUTO restores the retained analyzed value. If the current sample has no retained result—for example after project recall—AUTO re-analyzes it on the loader worker and applies a valid result. This source tempo defines beat distances inside the file; it does not force the instrument to follow host tempo.
  4. Set SPEED. Its default of -7 semitones lowers the playback rate, pitch, and duration together; positive values raise them together.
  5. Drag the waveform's S and E handles to select a region. Choose ON from the LOOP menu when the two copies should remain inside it.
  6. Press RESTART. Deck A starts at S and Deck B starts at Deck A plus B OFFSET, measured in source beats.
  7. Set A LEVEL and B LEVEL, then move the crossfader between them. The deck levels are smoothed before the crossfade; OUT remains the post-crossfade master. XFADE CURVE provides CUT, SHARP, and equal-power BLEND.
  8. Use SYNC to restore the selected offset, STEP - and STEP + for discrete moves, or B LIVE PHASE for an immediate continuous nudge. A P/P and B P/P pause individual decks when LINK is off. Hold DRAG A or DRAG B to slow that deck temporarily; release it for a smooth return to its normal rate. Set CUE PREROLL for the reaction time between hearing a target and pressing CUE A or CUE B. Use its TRIG button for repeatable restarts, or drag an existing colored cue marker to place it directly on the waveform.
  9. Sequence the command notes from s3g Tracker. The complete mapping is published through the CLAP note-name extension, so supporting hosts can display the commands by name.

Working with Two Decks

Use Speed to establish the shared playback rate, then choose how the two decks contribute to the output. Cut and Sharp curves support quick changes between decks, while Blend combines them more gradually. A Level and B Level set the balance before the crossfader. Punch commands temporarily favor one deck, and cue triggers provide repeatable starts from chosen points in the source.

Deck B's timing controls offer several distinct kinds of movement. B Offset defines the position applied by Restart or Sync, B Live Phase moves the deck immediately, Phase Step makes repeatable discrete moves, and B Drift creates continuous separation over time. Press Sync whenever you want to return to the stored relationship.

Deck Timing

SPEED changes playback rate, pitch, and duration together. Both decks use this common rate. B DRIFT adds a fine speed difference to Deck B only, from -100 to +100 cents. Very small values create a slowly changing relationship; larger values move through alignments quickly.

B OFFSET is stored in beats but does not teleport Deck B whenever its slider moves. Press Sync or Restart to apply it. B LIVE PHASE is deliberately separate: moving it shifts Deck B immediately and precisely by its change in source beats. MIDI notes 48–60 select a signed stored offset and synchronize Deck B immediately. Phase Step moves the existing Deck B playhead backward or forward without changing either control.

Phase Step, Loop, Crossfader Curve, MIDI Receive, and Link are categorical or toggle settings. Speed, Sample BPM, Start, End, Cue Preroll, output level, both deck levels, Deck B Offset, Deck B Drift, Deck B Live Phase, and the crossfader remain continuous controls.

With Loop enabled, synchronization, offsets, drift, live phase, and phase steps wrap inside the selected S–E region. Without Loop, each deck stops when it reaches E. Stop silences both positions; Play resumes them, while Restart returns to the beginning and reapplies the offset. Link is enabled by default so either deck Play/Pause button operates both decks; disable it to stop and resume the two copies independently.

Drag is momentary rather than a saved speed setting. While held, that deck slows according to the incoming note velocity; on release it eases back to the shared playback rate. Mouse release, MIDI note-off, editor close, and transport reset all release the gesture.

Each deck has one persistent cue point. Cue looks backward from the current read head by CUE PREROLL (0–1000 ms, default 150 ms), replaces the previous cue, and snaps to the nearest available zero crossing to reduce clicks. The lookback is measured in heard time: varispeed, Deck B drift, and a held Drag gesture change the corresponding source-frame distance, and Loop wraps the lookback inside S–E. The cyan or orange marker is drawn only in that deck's waveform lane. Click and drag an existing marker to place it directly under the mouse; mouse placement bypasses pre-roll but still snaps to a zero crossing. Trigger is a one-shot action: every press moves that deck to its cue and starts it, without moving the other deck or clearing the marker. Loading a different source clears both cues.

A practical Tracker layout uses one sparse lane for Restart, Sync, offset selection, and cue setting, one lane for Punch A, and one for Punch B. Add Trigger, Drag, or independent deck-toggle notes where a retrigger, temporary slowdown, or one-sided pause belongs. These are ordinary notes, so Tracker's microtime, delay, repeat, ratchet, flam, stutter, probability, note length, and per-step volume can shape the performance directly. VOL sets both Punch depth and Drag strength: full velocity gives the deepest slowdown, while lower values leave more of the deck's normal speed. With the Cut curve, Tracker's normal note velocity is already deep enough to cross the narrow center transition; full volume lands completely on the punched deck.

Factory Presets

The five starting configurations below are available from the plugin's PRESET menu. They set the two-deck performance relationship while preserving the loaded sample, analyzed or manual BPM, S–E region, cue points and pre-roll, MIDI channel, Link state, deck levels, and master output.

PresetSettingsGesture
Rhythmic SwitchingSpeed -7 st; Offset +1 beat; Drift 0; Step 1/4; Cut; crossfader A; Loop offRestart on the phrase, then alternate gated notes 40 and 41. Use short repeats or flams for phrase fragments and attacks.
Trailing DoubleSpeed -7 st; Offset +1/2 beat; Drift 0; Step 1/4; Sharp; crossfader A; Loop offPunch B at phrase endings, then release back to A.
Stepped PhaseSpeed -7 st; Offset 0; Drift 0; Step 1/8; Blend centered; Loop onPlace note 42 at uneven polymetric intervals and note 38 at formal return points.
Gradual PhaseSpeed -7 st; Offset 0; Drift +0.35 cent; Step 1/4; Blend centered; Loop onLet the copies move from unison through changing attacks and comb-like cancellations; use Sync to begin a new phase cycle.
Offset MotionSpeed -7 st; Offset +1 beat; Drift +0.35 cent; Step 1/4; Blend centered; Loop onBegin with a clear beat displacement, allow slow motion around it, then use note 54 for immediate unison or note 58 for a one-beat return.

The stepped and gradual settings let identical repeating material begin together, separate through a small rate difference, pass through intermediate relationships, and reunite. Doubles keeps that process performable by adding explicit Sync and Phase Step commands alongside the continuous B Drift control.

Routing and State

  • Input: one CLAP note/MIDI command port and file loading through the editor.
  • Output: one fixed stereo port. Mono files are presented on both lanes; stereo channel order is preserved.
  • MIDI Receive: Omni by default, or Channel 1 through Channel 16.
  • State: all seventeen parameters, both normalized cue points and validity, source path, embed choice, and optionally as much as 1 GiB of decoded mono or stereo audio. Version-one twelve-parameter, version-two sixteen-parameter, and version-three cue-state projects remain readable. Versions one and two begin without cue markers; every older version receives the 150 ms Cue Preroll default.
  • BPM analysis runs only on the sample-loader worker. Project recall restores the saved source BPM exactly. Because an analyzed candidate is not serialized, pressing AUTO after recall starts a non-blocking rescan; changing files while it runs invalidates the stale result.
  • The audio engine keeps one immutable source asset and two positions; it does not duplicate the decoded audio in memory or include an internal recording stage.
