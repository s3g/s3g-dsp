Sample Rings

s3g Sample Rings 8 is the unified successor to Processor Loop and Processor Multi Loop. Its four slots can load files or record the signal arriving from the DAW and upstream effects. Every usable channel becomes a concentric loop ring—up to eight per slot and 32 in total—and eight read heads move through that radial source field without baking the files into one composite.

Workflow

  1. Insert s3g Sample Rings 8 on a fixed eight-channel REAPER track. Leave Store Project selected for project-contained media, or choose Link or Embed, then load or drop files into slots A–D. You can instead route audio from the track or an earlier effect into the plug-in and record a slot.
  2. Route the eight ordinary output lanes to the intended main speaker outputs, a downstream direct panner, or Output Autogain Stereo/Quad for fold-down monitoring.
  3. Choose a Radial Path and Head Formation, then choose the Angular Model among the eight heads. The Field Path and Head Clocks columns separate the two layers, while Master Rate scales both. The field shows the actual ring, source channel, loop phase, crossfade, and formation of every enabled head.
  4. Select a source row and set its Start, End, Speed, pitch-preserving Stretch, Pitch, Wrap Nudge, Gain, and Reverse state.
  5. Set Loop Join and Seam Duck, then audition without MIDI using Play, Pause, Stop, and Sync. Pause retains position, Stop pauses and returns the motion system to its start state, and Sync relaunches without changing whether transport is running. Finally choose direct eight-channel, quad-ring, or stereo-ring output.

Four Independent Loop Sources

Slots A–D retain separate audio assets and clocks. Files do not need equal durations, sample rates, or channel widths. The first eight channels of each loaded file become adjacent rings, ordered A1–A8, B1–B8, C1–C8, and D1–D8 as available. A mono file contributes one ring, stereo contributes two, and four eight-channel files fill the 32-ring field. Two-tone muted teal separator rings demarcate each file boundary without competing with the channel waveforms or read heads. The selected slot's waveform band brightens while the other slots remain in a closer neutral grayscale, so selection—not the letter A–D—determines visual priority. Click a source badge to select its controls. Multiple-file drag and drop fills consecutive slots.

ControlBehavior
Start / EndSet a proportional loop window for the selected source only.
SpeedChanges that source's transport speed and pitch together from one-eighth to four times rate.
StretchChanges elapsed loop time without changing the pitch established by Speed and Pitch. A dual-window overlap reader moves between direct and stretched playback.
PitchTransposes the selected source by as much as four octaves without changing its transport speed.
Wrap NudgeRotates source content by as much as half a loop. The waveform moves visibly and a dashed line identifies the wrapped seam.
Loop JoinCrossfades the outgoing end of every active loop into its beginning. It is global because a head may cross source boundaries.
Seam DuckAdds attenuation around the center of the join when overlapping endpoints would otherwise build up.

Project, Link, and Embed Storage

The title-bar Store button applies one Sample-family storage policy to all four file slots. New instances default to Project. Loading and content verification run away from the audio thread.

ModeSaved-source behavior
ProjectCopies each loaded file into the saved REAPER project's s3g Samples media directory and saves a project-relative locator. Content hashing reuses an existing verified copy when the same unchanged file is loaded again; files already inside project media are reused in place.
LinkKeeps the original external file path and writes no audio payload for a file-backed slot.
EmbedStores decoded floating-point audio for every populated slot inside the project, subject to the shared one-gigabyte safety cap.

If Project is selected before the REAPER project has been saved, the source plays from its original path and reports Project Pending / Save Project. The plug-in copies it once the project supplies a media directory. Changing storage mode does not interrupt playback. A live capture has no file to copy or link, so it remains embedded under every mode.

DAW Input and Capture

The plug-in reports one paired eight-channel input and output. It records the audio that reaches its input, so the source can be a track item, live interface routing, a send, or the output of plug-ins earlier in the same chain.

ControlBehavior
TargetSelects slot A, B, C, or D for recording and selects the same row for editing.
Input WidthAuto follows the highest active input lane. An explicit value from 1–8 captures exactly that many channels. Stereo normally uses input lanes 1–2; a wider source uses lanes 1 through the chosen width.
ReplaceStarts a new loop and replaces the target slot when recording stops.
OverdubRecords around the existing slot duration and adds input to retained material using Overdub Feedback.
PunchRecords around the existing slot duration and replaces the corresponding interval rather than summing it.
QuantizeStarts and stops freely or at the next beat, bar, two-bar, four-bar, or eight-bar boundary when the host supplies tempo and beat position.
MonitorLoop hears the matrix, Input hears the incoming lanes in place, and Both combines them with equal-power attenuation.

Record and stop from the editor when using Overdub or Punch so the existing slot can be prepared before realtime processing begins. Capture buffers are allocated at activation; the audio thread does not allocate memory while recording.

Concentric Source Field

The field is a literal view of the reader. Radius identifies a packed file/channel ring and angle identifies normalized time within that ring's own loop. Each circular trace now combines a faint sampled-peak envelope, a stronger RMS-energy band, and a fine signed contour. This preserves recognizable sections, transients, and level changes that a single-point trace can miss; every channel is normalized against its own sampled peak for legibility, so band width describes relative structure rather than absolute gain. Wrap Nudge visibly rotates the analysis with the loop content. Two dots connected across adjacent rings show the two independently clocked reads being combined, and their brightness follows the equal-power crossfade. The thin bridge appears only while both reads make an audible contribution; hard selection and completed crossfades show only the active dot. A two-tone muted teal circle marks each boundary between populated source files.

Radial PathRing motion
Fixed RingHolds around Ring Position. Formation Spread can place separate formations at different radii.
Outward / InwardSweeps once through the packed rings in the named direction, then wraps.
BounceTravels outward and inward without a radial discontinuity.
Sine SweepEases at the inner and outer turnarounds.
Stepped BandsMoves among four discrete radial regions.
Random WalkChooses a repeatable seeded ring region at each of sixteen path steps.
ManualUses the Manual Ring value of each free head or formation leader. Drag a head anywhere in the circle to enter Manual radial and angular editing.

Master Rate is the editor label for the host's Playback Rate parameter and is the common master for angular playback and radial motion. Each source's angular clock additionally follows its own loop duration, Speed, Stretch, and the selected Angular Model. Radial Ratio scales a stable eight-second reference cycle instead of borrowing slot A's duration: at Master Rate 1x and Radial Ratio 1x, Outward or Inward traverses the field in eight seconds, while Bounce or Sine completes an outward-and-return cycle in eight seconds. This keeps radial behavior unchanged when files are reordered or replaced. Rad Rev reverses path time from its current phase and therefore applies to every moving path, including Bounce, Steps, and Random; it is inactive for Fixed Ring and Manual. Fixed and Manual do not advance a hidden radial clock, so choosing a moving path later begins from the visible phase. Ang Rev independently reverses audible playback and displayed movement around every ring. Ring Position centers shaped motion, Depth sets its radial range, Offset changes starting path phase, Form Spread offsets separate free heads or groups, and Slew rounds jumps. Field 8 has one radial group, so Form Spread is intentionally inactive. Ring Blend moves from hard adjacent-ring selection to a smooth equal-power crossfade.

Factory Presets and Conditional Controls

The title-bar Preset menu contains eleven starting points ranging from Slow Field and Four Loop Pairs to Stepped Relay, Random Constellation, and Stereo Fold. Factory presets reset the motion, head, loop, MIDI, and routing controls while preserving the current Output Gain and all four loaded or captured sources. Editing a factory or loaded preset appends * to its title until another preset is applied, loaded, or saved. The adjacent Load and Save buttons continue to manage complete user state presets.

Controls that the current mode cannot use are dimmed, show a short reason in place of their value, and do not accept editor gestures. Their stored values remain intact for automation and return when the relevant mode is selected. Examples include Radial Ratio in Fixed or Manual, Formation Spread in Field 8, Overdub Feedback outside Overdub, Rotate in 8 Direct, Root while MIDI is Off, and slot controls when the selected slot is empty. Manual Ring, Phase, and Rate receive a muted teal emphasis when their respective Manual model is selected. Motion Seed replaces the older Path Seed label because it conditions both Random radial motion and seeded angular drift.

Head Formations and Source Width

Formation controls radial linkage only. Every head keeps its own angular phase and rate, so an eight-head Canon or Orbit remains eight distinct clocks even when all heads cross source bands together.

FormationRadial behavior
Free HeadsAll eight heads can occupy and cross arbitrary packed rings independently.
Linked PairsH1–H2, H3–H4, H5–H6, and H7–H8 share radial motion. Inside each source, the members address successive channels modulo that source's width.
Linked QuadsH1–H4 and H5–H8 form two radial rakes while retaining four separate angular clocks per rake.
Field 8All heads form one rake. With four eight-channel files, H1–H8 move coherently from A1–A8 through B1–B8, C1–C8, and D1–D8.

Narrower sources wrap channel correspondence inside a linked formation: a stereo file repeats channels 1–2 across the eight heads and a mono file supplies its one channel to all heads. Free Heads instead treats every packed channel as an independent radial destination. Empty slots contribute no rings and are skipped automatically.

Eight-Head Motion

Head ModelMotion
UnisonAll enabled heads start together and run at the same relationship rate.
CanonOffsets launch phase progressively while retaining a common rate.
FanSpreads rates continuously around Head Pivot. Negative Amount mirrors the fast and slow sides.
RatioMoves toward the fixed set 1/2, 2/3, 3/4, 1, 4/3, 3/2, 2, and 3. Negative Amount assigns that set to the heads in reverse order.
ShearCombines a smaller phase fan with a smaller rate fan.
OrbitStarts around the loop and gently modulates head rates around the ring.
DriftAssigns stable slow deviations to the heads. The separate Drift control can add a smaller deviation to any model.
ManualUses the phase and signed rate stored for each head. Manual Rate spans −4x to +4x: negative values counter-rotate that head and 0x stops it. Drag a head around the circle to set phase and radius together, or use Manual Phase and Manual Rate in the selected-head panel.

Angle Amount is bipolar from −1 to +1. Its sign reverses Canon phase order, mirrors the head ordering of Fan, Ratio, and Shear, and inverts Orbit or Drift modulation; 0 collapses the relationship toward unison. Head Pivot chooses the neutral head for rate-spread models, while Angle Glide smooths relationship changes. Click H1–H8 to select a head. The selected-head panel reports its effective ring read, phase, rate, source/channel read, crossfade, and linked group during automatic motion. Manual Ring replaces its ring readout only in Manual radial mode; Manual Phase and Manual Rate replace their live readouts only in Manual angular mode. Mute toggles that head; Solo leaves only it sounding and restores the previous head mask when released. Option-clicking a head remains a fast mute shortcut. Manual Ring edits the selected free head or the leader shared by its linked formation, while Manual Phase and Manual Rate remain per head. Manual Phase is displayed as a wrapped −180° to +180° position, and a signed Manual Rate composes with global Ang Rev and the selected slot's Reverse.

MIDI and Output

MIDI Off leaves transport under the Play, Pause, Stop, and Sync buttons. Gate plays while one or more notes are held. Trigger relaunches the field on note-on. In Gate and Trigger, note number changes Playback Rate around Root without altering the independent per-slot Pitch parameter.

8 Direct preserves all eight matrix outputs. Quad Ring and Stereo Ring project the eight lanes into a four- or two-channel ring while retaining the fixed eight-channel host port; unused outputs are silent. Rotate turns the ring before projection.
