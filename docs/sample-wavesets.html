Sample Wavesets

Sample Wavesets 2 and Sample Wavesets 32 read one mono or stereo recording as short groups of rising-crossing cycles. Both follow the familiar Sample Player layout: one source waveform, Start and End boundaries, a Loop Start and Loop End region, chromatic MIDI playback, and selectable play and voice modes. Wavesets 2 has a fixed stereo output. Wavesets 32 assigns each newly triggered voice to a channel or stereo pair within a user-selected 2–32-channel routing width while retaining one fixed 32-channel host port.

Workflow

  1. Choose Sample Wavesets 2 for stereo playback or Sample Wavesets 32 when notes should be distributed across a multichannel destination. Press LOAD SAMPLE or drop a mono or stereo file on the waveform, then choose STORE PROJECT (the new-instance default), STORE LINK, or STORE EMBED as described in Sample Storage.
  2. Route Wavesets 2 to a stereo monitor path. For Wavesets 32, set the host track to 32 channels, select an active OUTPUTS width from 2–32, and route the required portion of that bus.
  3. Drag S and E on the waveform, or use the Start and End sliders, to define the playable window.
  4. Place LS and LE inside that window and choose a looped Play Mode when the region should repeat.
  5. Choose the source interpretation, then select Poly, Mono, or Legato voice behavior and an Auto, Gate, One Shot, or Toggle trigger. In Wavesets 32, also choose mono or stereo-pair voice output, pair layout, and route order.
  6. Set Root, Tune, and Fine, then play chromatic MIDI notes. The PLAY button auditions the root note; STOP / KILL ALL clears every voice.
  7. Adjust Group, Repeat, Stride, Time, and Order to control how playback moves through the analyzed crossing map.
  8. Choose a Process and raise Depth when transformation is wanted. Join reduces discontinuity at repeated cycle boundaries.

Sample Range and Play Modes

Start and End define the complete playable window. Loop Start and Loop End are absolute source positions constrained inside that window. The four waveform labels are handles: clicking or dragging near one moves the nearest boundary, while the matching sliders provide the same automation-ready values. Scroll over the waveform to zoom around the pointer, Shift-scroll to pan, and double-click away from a handle to fit the complete source again.

The waveform and scope draw one numbered lane per loaded source channel. In polyphonic playback the scope explicitly follows the newest-triggered active note; the note number beside the Process name identifies that voice. Gray shows its ordered source group and the channel color shows the processed result. The two vertical bounds enclose the group, while internal divisions retain each analyzed cycle's measured duration rather than stretching every cycle to equal width. Scroll over the scope to scale the bounded group between a compact overview and a detailed view, or double-click to fit the bounds exactly. The internal analysis document stores a crossing map for every source lane plus a summed map. Both plug-in forms share this map, engine, scope, and cursor model; only their output stage differs.

Wavesets 32 Output Routing

Wavesets 32 always reports one 32-channel output port to the host. OUTPUTS limits the active assignment domain to any value from 2 through 32; it does not change the physical port. This keeps project routing stable while allowing, for example, a valid eight-channel performance inside the wider bus. New voices receive a route only when triggered and keep that route until they end. Changing a routing control resets the sequence used by future triggers without moving sounding voices.

Reverse SequentialAdvance from the highest destination to the lowest and wrap.

True Stereo keeps the source's left and right maps separate when the voice uses a stereo pair. Left Mono, Right Mono, and Sum Mono duplicate their result across both members. A mono voice destination sums a True Stereo source. Mono and Legato voice modes advance the allocator on every accepted key press; Poly voices layer while retaining their independently assigned destinations. Each playhead flag includes the destination channel or channel pair.

Voices and MIDI

MIDI notes are pitches, centered on Root. Tune moves all notes in semitones and Fine supplies cent offsets. Poly layers as many as sixteen voices. Mono replaces the active voice on each note. Legato preserves the current waveset position and amplitude while retargeting its pitch. Velocity blends between fixed level and note velocity according to the Velocity control.

TriggerNote-off behavior
AutoOne-shot modes ignore note-off; loop modes release on note-off.
GateEvery voice releases when its note ends.
One ShotNote-off is ignored; playback follows the selected range and Play Mode.
ToggleRepeated note-on alternately starts and releases the matching note.

MIDI defaults to Omni and can be restricted to channels 1–16. Attack and Release are time controls from 0–2 seconds. Every active voice has an independently moving compositor playhead with an N note-number flag. The neutral Sample Player cursor colors repeat across the sixteen available voices, while staggered flags keep polyphonic notes distinguishable.

Waveset Playback

ControlFunction
DetailRaw follows eligible crossings directly. 8 kHz, 4 kHz, 1 kHz, and 250 Hz progressively smooth only the analysis signal and tend toward longer pseudo-cycles.
Group / RepeatCombine 1, 2, 4, 8, 16, or 32 adjacent cycles and repeat the complete group 1–16 times.
StrideMove by 1–16 groups after each repeated unit. The selected Play Mode supplies forward or reverse source direction.
TimeStretch advances one Stride after all repeats. Preserve advances by Repeat × Stride. Hold remains at one source group.
OrderRead cycles inside a group Forward, Reverse, Pendulum, or Shuffle without changing the Play Mode direction.
Basic ProcessRepeat leaves cycles intact. Omit removes selected cycles, Replace substitutes a strong cycle, Envelope applies a cycle-synchronous contour, and Multiply makes one phase-multiplied read.
Average / InterpolateAverage aligns and averages every cycle in the group. Interpolate morphs each repeated cycle toward its adjacent source cycle, including a gradual change of cycle length.
Fractal / HarmonicFractal adds recursively smaller power-of-two copies of the cycle. Harmonic performs true additive integer-ratio copying; it is distinct from Multiply.
Group / Cycle ReverseGroup Reverse reverses cycle order and the samples inside each selected group. Cycle Reverse reverses samples inside each cycle without changing group order.
TelescopeSuperimpose all cycles in the group against a shared cycle duration. Increasing Depth also skips more of the component cycles, contracting the group toward one composite cycle.
Depth / JoinDepth controls transformation strength. Join applies endpoint correction within each cycle to reduce repeated-boundary steps.

Tracker and Automation

Tracker can sequence the instrument like a conventional chromatic sampler on one MIDI channel. Note length becomes musically significant in Gate and looped Auto modes; velocity is available directly from Tracker's volume column.

All 25 Wavesets 2 controls are CLAP-automatable. Wavesets 32 adds Output Order, Voice Output, Stereo Pair Map, and Output Count for 29 parameters. Parameter automation is preferable when exact stepped menu values or reproducible range positions are required.

Routing and State

  • Input: one CLAP note/MIDI port plus file loading and drag-and-drop in the editor.
  • Wavesets 2 output: one fixed stereo port. “2” identifies this channel count rather than a number of decks or voices.
  • Wavesets 32 output: one fixed 32-channel host port. The active 2–32-channel routing width is saved and automatable; unused physical lanes remain silent.
  • State: all 25 or 29 parameters, requested storage policy, preserved source reference, and—in EMBED mode—up to 1 GiB of decoded mono or stereo PCM.
  • Analysis and file decoding run away from the audio callback. Audio rendering uses immutable per-channel and summed crossing maps.
  • On macOS, each voice cursor uses the persistent compositor trajectory established for Sample Doubles. The waveform playhead is a continuous source-transport indicator that begins exactly at Start and spans every displayed channel lane. The bounded scope follows the newest-triggered voice, compares its ordered source group with the processed result per channel, preserves measured cycle proportions, and reports note, group, cycle, repeat, phase, Depth, and view scale. The 30 Hz AppKit timer services the scope and static feedback, not visible waveform-playhead movement.

PROJECT copies the unchanged source in the background into the saved REAPER project's effective media directory under s3g Samples; LINK retains the original path; EMBED adds decoded 32-bit floating-point PCM to plug-in state. A pending Project request in an unsaved or unsupported project keeps the source and unresolved reference intact. Because hosts can snapshot complete state for undo during FX bypass or chain edits, large embedded sources may cause pauses even when audio processing itself is light.
