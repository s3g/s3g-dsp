Sample Wavesets

Sample Wavesets loads one mono or stereo recording into two free-running waveset decks. Both decks use the same analyzed source but retain independent positions, speeds, levels, phases, and play states. Shared waveset controls determine how groups are repeated and transformed; a continuous crossfader cuts or blends between the two results.

Workflow

  1. Press LOAD or drop a mono or stereo file on the overview. Leave EMBED enabled to store decoded audio with project state, or choose PATHS to retain only the file location.
  2. Route its fixed stereo output to the intended speakers or monitor path.
  3. Choose DETAIL. Raw follows every eligible crossing; the frequency choices low-pass only the analysis reference, producing progressively longer and more stable units without filtering the audible sample.
  4. Set GROUP large enough that the source remains recognizable, then use REPEAT to expose its internal cycles.
  5. Choose TIME: STRETCH to retain every successive group, PRESERVE to skip ahead in proportion to Repeat, or HOLD to remain on one group.
  6. Set STRIDE and ORDER. Stride controls movement between source groups; Order changes cycle order inside each group without changing the overall source direction.
  7. Set the initial POSITION, SPEED, and LEVEL for Deck A and Deck B. A click or drag in either waveform row moves that deck directly.
  8. Use each deck's PLAY/PAUSE, STOP, and RESTART buttons. LINK makes either deck transport address both; the shared transport always addresses both.
  9. Move the crossfader toward A or B, and choose Cut, Sharp, or Blend as the response.
  10. Choose PROCESS and raise DEPTH. Use JOIN to reduce boundary steps between repeated pseudo-cycles.

Crossing Map

A pseudo-wavecycle runs from one rising zero crossing to the next. The analyzer estimates each crossing between samples and retains that fractional position, avoiding the systematic phase error caused by rounding every boundary to an integer frame. Mono files use their single lane. For stereo files, analysis chooses the channel with the greater energy and applies that one boundary map to both lanes. This avoids inventing boundaries through stereo phase cancellation and preserves left/right timing during playback.

DETAIL changes analysis resolution rather than the rendered tone. Raw is most sensitive to high-frequency structure. The 8 kHz, 4 kHz, 1 kHz, and 250 Hz choices progressively smooth the reference used for crossing detection, so the map tends toward longer units. Changing Detail starts a background reanalysis and retains the immutable source audio.

Playback and Processing

ControlFunction
TimeStretch advances one Stride after all repeats. Preserve advances by Repeat × Stride, retaining approximate source duration by omitting intervening groups. Hold repeats the current group without source movement.
Group / RepeatCombine 1–32 consecutive pseudo-cycles into one unit and repeat that complete group 1–16 times.
StrideMove by -16 to +16 groups. Positive values follow the recording; negative values move backward; zero keeps one source group.
OrderRead cycles inside each group Forward, Reverse, Pendulum, or Shuffle. Source groups still follow Stride.
ProcessRepeat leaves cycles intact. Omit removes selected cycles, Replace substitutes the strongest cycle in a group, Envelope applies a cycle-synchronous Hann contour, and Harmonic multiplies the internal phase.
DepthControls the strength of Omit, Replace, Envelope, or Harmonic processing.
JoinApply endpoint correction within each cycle to reduce repeated-boundary steps.
Deck position / speed / levelSet each deck's restart position, source-relative playback speed from 0.25× to 4×, and pre-crossfader level.
Crossfader / curveMix continuously from Deck A to Deck B. Cut gives a narrow handoff, Sharp retains a short overlap, and Blend uses an equal-power curve.

PLAY/PAUSE holds the current deck position and resumes it. STOP silences the deck and returns it to its Position setting. RESTART returns to Position and immediately begins playback. The short internal ramps suppress transport clicks. OUT is the stereo master and appears first in the left control column.

Tracker and MIDI

MIDI CH selects one receive channel for the whole instrument. Notes are transport commands rather than pitches, which makes the decks predictable in Tracker patterns without requiring sustained note gates.

This lets Tracker sequence deck starts, stops, offsets, speed changes, and crossfader cuts while both streams otherwise run freely. Use longer groups for recognizable source gestures, small groups for timbral distortion, Stretch for expanded phrases, Preserve for denser transformation at approximately the original duration, and Hold for stationary groups. All 20 controls are CLAP-automatable.

Routing and State

  • Input: one CLAP note/MIDI port plus file loading through the editor.
  • Output: one fixed stereo port. Mono files feed both lanes; stereo boundaries and channel order remain shared and coherent.
  • State: all 20 parameters, source path, embed selection, and optionally as much as 1 GiB of decoded mono or stereo audio. The crossing map is rebuilt from the restored source and saved Detail setting.
  • Analysis and file decoding run away from the audio callback. The render path uses an immutable source and precomputed boundary map.
  • On macOS, the cyan and orange deck playheads use persistent compositor animations derived from the Sample Doubles solution. The 30 Hz AppKit timer handles meters and button feedback but does not drive visible cursor motion.

The instrument's waveset terminology and grouped-cycle approach follow the pseudo-wavecycle processes documented by the Composers Desktop Project. See References for the source material used in this design.
