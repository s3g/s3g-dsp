Drum Mixer 16

Drum Mixer 16 collects eight stereo drum lanes inside one CLAP effect. Its fixed 16-channel input and output ports are designed for REAPER's plug-in pin connector: each source occupies one input pair, then the mixer either creates a stereo master or returns all eight post-strip pairs as direct outputs.

This mixer is included in the 0.7 CLAP archive. Its host-independent DSP boundary is shared with the drum and tracker toolchain.

Workflow

  1. Set the REAPER track to at least 16 track channels and insert s3g Drum Mixer 16 after the drum sources.
  2. Route outputs 1/2 to the main stereo output or a headphone monitor so the summed mode has an audible path.
  3. Use each upstream drum plug-in's pin connector to place its stereo output on a distinct pair: 1/2, 3/4, through 15/16. The mixer consumes those pairs as lanes 1–8.
  4. Choose SUM for a stereo mix or DIRECT when downstream plug-ins, receives, or hardware outputs need the individual pairs.

Parallel Drum Bus

AUX BUS enables an original parallel processor assembled for the s3g drum family. The ROOM direction follows the useful production idea demonstrated in Brian Funk's Drum Buss room-noise example: negative settings retain attacks while contracting body and tails; positive settings lift body and room energy. The implementation is not an emulation of Ableton's device.

Master and Headroom

OUT controls only the summed output. Its −6 dB default leaves headroom when several synthesized drums coincide. The mixer does not place a safety limiter after the master: use the lane faders, AUX return, and output level to control peaks deliberately.

Automation and State

All 81 parameters are automatable. INIT resets the complete mixer, while LOAD and SAVE exchange the routing mode, output and bus controls, and all eight strip states. Version 1 mixer states load with the new Mid Frequency controls at their 900 Hz default. The fixed port count does not change when a preset selects a different output mode, so REAPER pin assignments remain stable.

Limits

The plug-in requires one 16-channel input and one 16-channel output port. It does not accept MIDI, rename lanes, create additional host ports, or include the AUX return in DIRECT mode. Direct outputs are post-EQ, post-pan, post-fader, and post-mute/solo.
