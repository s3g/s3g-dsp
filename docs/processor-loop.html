Processor Loop

s3g Processor Loop 8ch is a CLAP instrument plugin for loaded audio loops. It does not process track input; it plays a selected sound file across eight output lanes.

Playback is lane based rather than topology based. A loaded mono, stereo, or multichannel file is repeated across the eight outputs, and each lane has its own playhead, phase, and rate relationship within a shared loop region.

Workflow

  1. Insert s3g Processor Loop 8ch on an 8-channel REAPER track.
  2. Leave FORMAT at 8CH DIRECT for discrete routing, or select QUAD RING or STEREO RING for an internal monitoring fold-down.
  3. Click LOAD and choose an audio file, or drag a supported audio file from Finder onto the plugin window.
  4. Use the transport icons to play, pause/resume, or stop and return the lane playheads to the start.
  5. Use the output lane strip to enable or mute individual lanes.
  6. Shape lane timing with the relationship and loop sections.
  7. Use SYNC to realign lane playheads after editing loop timing.

If the loaded file has fewer than eight channels, source channels repeat across the eight output lanes. For example, a stereo file maps odd lanes from channel 1 and even lanes from channel 2.

Display

The waveform shows the loaded channel with the strongest activity. Loop start and length are drawn as markers over it, while thin overlay cursors show where the enabled lanes are inside the loop region.

The relationship panel shows lane-rate differences as horizontal bars. The compact output strip enables or mutes individual output lanes without invoking the topology patch matrix model.

Engine

Control Meaning
RATEBase playback rate for all lanes.
XFDLoop seam crossfade as a percentage of the active loop length, capped at 30%. This keeps the seam proportional as LEN changes.
DUCKOptional seam ducking inside the crossfade window.
OUTOutput gain after lane playback.
FORMAT8CH DIRECT preserves the eight lanes. QUAD RING projects them into outputs 1–4; STEREO RING projects them into outputs 1–2. The host bus remains eight channels and unused outputs are silent.
ROTATERotates the eight source lanes around the quad or stereo ring from −180° to +180°. It has no audible effect in 8CH DIRECT.
STRTLoop start position inside the loaded file.
LENLoop length. The default is the full file.

Relationships

Relationship controls change the timing among lanes. One global setting produces coordinated, lane-specific rates and motion across the eight outputs.

Control Meaning
SPRDBipolar rate spread. Positive values fan lane rates outward; negative values mirror the relationship.
DRFTBipolar slow drift amount. Negative values invert the drift direction.
CTRRelationship center. Moving it changes which lanes behave like the middle of the spread.
GLDGlide time for relationship changes, useful for automation and large jumps.

Transport

  • Play starts or resumes lane playback.
  • Pause holds the lane positions. Clicking pause again resumes playback.
  • Stop pauses and returns all lane playheads to the start.
