Sample Neon 32

s3g Sample Neon 32 is a performance sampler with 32 pad cells, up to 32 sample layers per cell, and nine playback methods. Chop recordings into pads or layer stacks, move through those layers, reshape the sound, and resample the result. It works with the on-screen controls, sequenced MIDI notes, or one or two Reloop NEON controllers without replacement firmware.

This guide covers version 0.39.0, including destructive-edit undo/redo, Cutups playback, custom pad-note maps and Spectral colour controls. One instrument handles stereo, discrete multichannel and ACN/SN3D Ambisonic sources. Its CLAP output is always 32 channels; the default Stereo layout mixes onto channels 1–2 and leaves the rest silent.

Workflow

  1. Insert s3g Sample Neon 32 on an instrument track. Start with the header's STEREO layout; for wider output, match the host track width to the selected layout.
  2. Establish monitoring on channels 1–2 before playing. Route wider output buses to the intended speakers or fold-down; Ambisonic output needs a matching decoder.
  3. Select cell A1 in PLAY. Drop a supported audio file on its pad, or choose EDIT VIEW → SOURCE / STACK → LOAD. Use AUDITION PAD to check the sound.
  4. Choose EDIT LAYER in the waveform-view menu to edit its Start/End and cursor. Keep ZERO CROSS on initially.
  5. Choose one PLAYBACK method in the persistent PAD toolbox, then open EDIT VIEW → PLAYBACK for its controls. Changing the edit view does not change the sound engine.
  6. For a sustained texture, start with HOLD and FREE / PAD clock. Use Attack/Release for the whole gesture; choose ONE SHOT and Shot Length for a timed gesture.
  7. Add sources with ADD LAYER, or use CHOP to distribute slices into pads or one pad's stack. Layer Src determines which layer sounds; Edit Layer determines which one you edit.
  8. Use CHARACTER FX for post-playback processing. Open RESAMPLE to capture an internal output bus, crop the take, and assign it to an empty cell.
  9. Choose PROJECT, LINK or EMBED storage, then save the host project or a reusable .s3gneon set. For a hardware/Tracker setup, follow the MIDI chain below.

Pads, Layers and Workspaces

The sound path is pad stack → one playback method → Character FX → output bus → master. Layer navigation moves between recordings inside one cell; source navigation moves through time within those recordings. Neither silently mixes adjacent cells.

ControlWhat it determines
Selected cellThe pad addressed by the PAD toolbox, source editor and contextual controls. Banks A–D contain eight cells each.
Edit LayerThe source targeted by loading, trim, slice construction and layer editing. Layer 1 is the primary.
Layer Src / NavigationWhich layer or blend the playback method reads. This can differ from Edit Layer.
Play Layer readoutWhat is actually sounding, including a blend, held layer, manual override or isolated edit-layer audition.
PlaybackThe cell's single active sound engine. Opening another toolbox does not select another engine.

PLAY includes performance and editing. Its Edit View menu contains SOURCE / STACK, PLAYBACK, STACK PATH, CHARACTER FX and ROUTING. CHOP constructs and auditions slices of the selected source. RESAMPLE records and edits a take. STACK switches the miniature controller to layer performance inside PLAY; it is not another instrument or playback engine.

The persistent PAD toolbox retains Playback, Layer Src/Navigation, Edit Layer, Trigger, Gain, Tune, Audition Pad and Stop Pad across these workspaces. It always addresses the selected pad, not the resample review. Audition Pad follows the pad's playback and source choices; AUDITION EDIT LAYER isolates the edit target where supported.

Loading, Editing and Copying Sources

Load mono, stereo, quad or octo discrete audio, or 4/9/16-channel ACN/SN3D audio. Each cell holds up to 32 layers with the same channel count. LOAD replaces the selected layer; ADD LAYER appends one. Dropping multiple files in the stack editor appends layers. REMOVE removes the layer from the instrument, not its file on disk.

Trim, slice markers and source-editing settings belong to each layer. Playback, gesture envelopes, Gain, Tune, Character FX, source format and output route belong to the whole pad. Source edits do not switch its playback method.

Normalize

SOURCE / STACK → NORMALIZE offers EDIT LAYER, STACK / EACH LAYER and STACK / KEEP BALANCE. Apply targets −1 dBFS: Each Layer normalizes every loaded layer independently; Keep Balance applies one gain to the entire stack, preserving relative levels. The latter is useful for velocity layers.

Normalization processes complete source samples, not only their trim windows. Every channel of a source receives the same positive gain. It is peak normalization, not loudness matching or an Ambisonic normalization conversion. The pad stops on commit; original files and copies in other cells are unchanged. Generated audio follows the chosen storage policy.

Copy and Paste

Focus a PLAY cell pad, then use Ctrl-C / Ctrl-V or Cmd-C / Cmd-V on macOS. Right-click offers Copy Cell and Paste Cell; Control-click also works on Mac. Change banks before pasting to copy across A–D. Replacing a populated destination requires confirmation.

A copy includes the entire stack, trims, slices, playback, envelopes, FX and routing. Later edits are independent, and pasting does not automatically audition. The clipboard belongs to this plug-in instance and is not saved with the project; it survives Reset All. Focused text fields retain normal text copy/paste.

Undo and Redo

The header's UNDO / REDO buttons are available on every page. The lower status area names the next action in each direction. With the plug-in canvas focused, use Cmd-Z on Mac or Ctrl-Z to undo; add Shift to redo, or use Ctrl-Y. Focused text fields keep their own text-editing shortcuts.

History covers successful file loads/replacements, Add/Remove Layer, Paste Cell, normalization, committed slices to pads or a stack, recorded takes, capture cropping/discard/assignment, and Reset All. A multi-pad slice assignment or whole-stack normalization is one step. Undo restores the affected pad's complete pre-edit audio and settings, including trims, slices, layers, playback and FX; subsequent setting changes on that pad are also rolled back to that checkpoint. Unaffected pads and global MIDI/controller connections are retained. Ordinary slider/menu changes and marker editing are not separate history steps.

Undo/redo stops sounding pads, fill and audition before restoring; it never retriggers notes or restarts recording. Finish recording or pending file loads first. A new destructive edit clears Redo. History is session-local: it survives closing/reopening the editor, but is not saved in projects or sets. Successfully loading a project/set starts fresh history; cancelled or failed loads do not. Save a set for durable recovery.

The journal keeps up to 32 edits and 512 MiB of unique referenced PCM across Undo and Redo, sharing unchanged audio. Older steps are dropped when needed. An individual snapshot above that budget is refused before editing. This is a history budget, not a limit on total plug-in memory. Restores must also fit the current embedded-audio storage limit.

Waveform and Zero Crossings

The waveform remains the same size when switching playback methods or toolboxes. Its view menu separates playback observation from source editing:

ViewBehavior
Follow StackFollows the sounding layer in Primary, Selected, Velocity and Random modes, and fades between layers during Stack Scan. Following does not change Edit Layer. The followed playback display is read-only.
Edit LayerShows a fixed editable source for cursor and trim work. Playback cursors appear when they belong to that source.
Stack LanesShows up to eight stack rows at a time, following the active region of a larger stack. Layer levels and read heads show playback; this is a read-only, combined-peaks display.

WAVE → ALL CHANNELS is the default: one aligned row per source channel. CHANNEL 1 / ACN 0 isolates the first channel visually. COMBINED PEAKS displays the min/max envelope across all channels, not a sum; opposite-polarity channels do not cancel. These views never solo, downmix or otherwise change the audio. The small overview always uses combined peaks.

Scroll vertically to zoom 1×–32× around the pointer. Shift-scroll or horizontal trackpad movement pans. Motion overlays its source field and cursors; Grains shows actual grain windows and read progress. Follow Stack and Edit Layer use vertical playback lines. CHOP and RESAMPLE keep their own fixed source/review views. View preferences and zoom are local to the instance, not saved sound settings.

ZERO CROSS searches near trim and slice boundaries, within approximately ±5 ms. A crossing shared by all channels is preferred. Otherwise it chooses a low-energy common boundary using the worst channel first, so channel cancellation cannot disguise a bad cut. Channels are never shifted independently. Disable snapping for exact manual placement; re-enabling it resolves the current boundaries. Difficult or DC-offset material may have no shared crossing, so the best local choice is not a guarantee of a click-free loop.

HOLD responds to pad/note release; TOGGLE continues until the next press. Generated methods with SHOT LEN use it for One Shot duration, not the file or grain length. Shot Length and gesture fades are captured at the strike: retrigger after changing them. Attack/Release shape the whole gesture and are separate from grain windows and per-slice ADSR. Stop Pad and KILL are explicit stops; FX can otherwise have tails.

FREE / PAD runs independently of transport. HOST TRANSPORT uses the host clock and exposes beat choices where applicable; use Free when a held texture should continue with transport stopped. Motion packet, motor and event rates remain Hz. Stretch uses Duration rather than a competing Shot Length; primary Wavesets Rearrange follows its source, while scanning Wavesets and Oscillator expose gesture timing.

Cutups

CUTUPS uses the actual Sample Cutups playback engine, adapted from four files to all loaded layers in the selected pad. It works with one layer, two or three, or a full 32-layer stack. LAYER ORDER replaces Layer Source: Down, Up, Palindrome, Random, Random Cycle, Pairs, Outside In, Center Out, Stagger or Manual. Random Cycle visits each loaded layer before reshuffling; Stagger extends its original four-layer figure through successive groups. Pattern length is independent of layer count: use at least as many steps as layers when a Down/Up pattern must visit every layer.

EDIT / PLAYBACK contains the original cut controls: Free rate (0.1–80 Hz) or Host Tempo divisions, Equal/Transient regions, shared Steps/Regions (1–64), Source Order, Step Repeat (1–16), Gate, Join, Swing, timing variation, reverse chance, pitch and level variation, Seed, Poly/Mono/Legato, Poly Path and Attack/Release. The original cut scheduler, seeded random stream and equal-power join processing are shared with Cutups. One Shot finishes one complete pattern including repeats; Hold releases at note-off and Toggle stops on the next pad press. There is no competing Shot Length.

Each layer keeps its own trim and source BPM. LAYER BPM edits the currently selected Edit Layer. Tempo Sync multiplies reading speed by host BPM / layer BPM and therefore changes pitch. Cutups' HOST TEMPO follows BPM even with transport stopped; it differs from the transport-gated clocks of Motion and Grains. Transient analysis uses the original default 1 ms preroll and runs off the audio thread. CHOP markers/preroll remain separate; Cutups does not consume the authored slice map.

The fixed strip below the waveform becomes a Cut Pattern graph. Click/drag chooses layer addresses and switches Layer Order to Manual. Option/Alt-click or drag writes a source position and switches Source Order to Manual. Edit Step, Step Layer and Step Source provide precise entry for dense stacks. Empty manual addresses resolve to the nearest loaded layer. The playing cursors and Follow Stack/Stack Lanes views follow the actual rendered layer; Stack Scan, Stack Path and held STACK-position overrides do not compete with Cutups' ordering.

Preserve Field keeps multichannel and ACN/SN3D channels coherent. For discrete Distribute routing, choose allocation per Note, Cut or Pattern within the pad's selected output bus. In EDIT encoder mode, LOOP changes rate/division and TRAX changes repeats; LOOP push auditions. Neon notes still select pads rather than transposing Cutups keyboard voices, and shared Tune controls pitch. Standalone Cutups factory presets are not imported.

Motion and Grains

Motion's Basic Path offers Forward, Reverse, Bounce and Wander; additional trajectories are Hover, Mirror, Zigzag and Moving Loop. SOUND chooses Continuous, Packets or Motor. Packet Rate/Duty set the inner pulse; Motor adds an outer Rate, Shape and Symmetry. Join Window sets source-window length. EVENT MODEL chooses Smooth, Freeze, Iterate, Doublets or Bounce, with rate, repeats, source step and variation controls.

Grains' GRAIN SRC selects Freeze, Scan, Cloud or Slice. Scan moves within the source; Cloud chooses positions; Slice uses equal regions, not the authored CHOP markers. Density/Interval sets emission timing and Size sets an individual grain window—not cloud duration. Window choices include Legacy, Parzen, Sine, Hann, Triangle and Gaussian, with skew, size/level variation and timing scatter. Processes include Ordinary, Sorter, Stutter, Shrink and Doublets; Amount and Regions shape their behavior.

These are Neon-specific integrations of Motion, Grains and Lanes, not complete copies of those instruments. There is one generated gesture per pad, and dense or long overlapping windows can exhaust the per-pad voice pool. Standalone keyboard mono/legato modes and independent per-layer Lanes transports are not imported.

Wavesets: Rearrange and Oscillator

ENGINE → REARRANGE uses Group, Repeats, Shape and Process to repeat, omit, replace, interpolate or reverse cycle groups. OSCILLATOR instead sustains a cycle GROUP selected by CYCLE POS; FREQUENCY sets its tuning and SCAN moves through source groups over SCAN CYCLE. Pad Tune additionally transposes it. A multi-cycle group can have prominent harmonics above the nominal fundamental. Oscillator is not a chromatic keyboard remap: MIDI notes still address pad cells.

Both engines offer Primary or Stack Scan and remain disabled for ACN/SN3D. Cycle analysis is prepared outside the audio callback. Silent/DC sources may have no usable cycles; no sound in that case is not evidence that a pad is empty.

Spectral Playback

Spectral uses phase-continuous 1024-point FFT resynthesis, not repeated grains. Begin with Hold and Free clock, select a moment with Position, and audition the pad. Advance at zero freezes the source position; Pressure Advance can still move it while a pad is pressed. Set both to zero for a fully stationary read. The analysis window introduces a short build-up, about 21 ms at 48 kHz.

ControlBehavior
PositionThe analysed moment within the trimmed source.
Advance / Press AdvContinuous scan speed plus pressure-driven advance, capped at full speed.
Scan CycleFull-speed traversal duration, in Free seconds or Host beats.
BlurSoftens the joint spectral energy envelope and slows changes; higher values can soften level as well as detail.
Smear, 0–4 sRetains earlier spectral energy as the source or stack changes. This is response time, not an echo or pad Release. A stationary frozen frame does not demonstrate it; move Position, Advance or the stack.
Focus, −1…+1Negative values flatten spectral contrast; positive values emphasize dominant peaks. Bounded joint-energy compensation limits loudness-only changes.
Tilt/Oct, −6…+6 dBDarkens or brightens around 1 kHz, with spectral gain bounded to −24/+12 dB. Leave output headroom; this does not retune partials.
Thin, 0…1Progressively removes stable three-bin bands for hollow, sparse textures. It does not choose a new random mask per strike or channel. High settings can remove nearly all of a narrow-band source.

Colour changes are smoothed separately from Smear so live edits remain responsive. Primary, Selected Layer, Velocity, Random / Trigger and Stack Scan are available. All channels share analysis positions, bin gains and phase handling; there is no independent-channel randomization or Ambisonic decoding. EDIT encoders remain LOOP = Position and TRAX = Blur, with Shift for fine adjustment.

Unavailable choices are disabled. Sample does not continuously scan layers; Wavesets exposes Primary/Stack Scan. Lanes replaces Layer Src with NAVIGATION → MANUAL / PATH. Slice Sequence uses the primary layer's markers in Sequence mode; Mosaic's Candidates menu can instead use the stack's slices.

Lanes is the direct layer-navigation method: one continuous read head keeps moving while LAYER POS or Previous/Next Layer changes the source. Crossfade blends neighboring layers; Jump selects the nearest. Layer Slew smooths transitions. Layers share normalized progress, using the primary/first loaded trim as the timing reference, so different-length layers can play at different effective rates. Speed/Tune are rate changes, not transparent time stretching. Loop Join smooths wrapping loops.

STACK PATH controls movement between layers, independently of movement within each source. Shape choices are Manual, Ramp Up, Ramp Down, Triangle, Sine, Square and Wander. Every shape uses the visible breakpoints; choosing a named shape regenerates them. Layer 1 is at the top, matching Stack Lanes. The moving dot and guide show path phase; a hollow dot indicates a held STACK override.

Click a point or empty graph space to switch to Manual without clearing the curve. Click empty space to add a point, drag to change time/layer position, and right-click or Control-click to remove an interior point. Endpoint times stay fixed, but their heights are editable. Use 2–32 points; named shapes enforce their minimum counts. Phase offsets the cycle and Curve bends interpolation. Grains can advance by Time or Grain Events. A breakpoint's Point Layer edits that node, not the current playing layer.

Hardware STACK pads temporarily steer an active compatible gesture to the held layer. STACK performance is unavailable for Slice Sequence and primary-only Wavesets; Wavesets needs Stack Scan. A manual LOOP movement latches an override; LOOP push or RESUME returns to saved navigation. Selecting Layer Src/Navigation also clears the latched override. A physically held layer retains momentary priority until released. Moving Lanes' Layer Pos takes Manual control. These overrides do not rewrite the saved breakpoint path.

Chop and Slice Sequence

CHOP works on the selected pad's edit layer. Live Markers, Transients, Equal and Beat Grid construct up to 32 slices; banks A–D address slices 1–8, 9–16, 17–24 and 25–32. Pads audition slices directly. Transient Pre-roll moves detections earlier by 0–50 ms before zero-crossing snapping. Returning it to zero restores the detections; turn Zero Cross off when an exact offset matters.

Assign commits new cropped audio, not merely trim references to the full source. Each new slice has its own fitted waveform, 0–100% trim and one region until re-chopped. All channels share the same cut. Choose the destination explicitly:

DestinationAssignment
Pad Cells / Start PadPlaces slices into consecutive cells, crossing banks but never wrapping beyond D8.
One Pad / Layer Stack / Target PadPlaces the slices as layers inside one destination cell.
Auto / EmptyFinds available empty destinations, skipping occupied cells.
Source cell / ReplaceExplicitly replaces the source stack. Pad distribution puts the first slice in the source cell; layer distribution replaces it with the slice stack.

The Assign buttons and ALL > readout show the planned destinations. Other occupied cells cannot be overwritten; insufficient room disables Assign All. Source replacement changes the plug-in's audio, not the original disk file. New pad slices start as forward one-shots, retaining source shaping and routing rather than automatically becoming a sequence.

SLICE SEQUENCE plays regions inside the pad, not neighboring pad cells. NAVIGATION → SEQUENCE uses the primary layer's markers with Forward, Reverse or Random order. Mosaic alternatives are Similar, Contrast, Energy and Brightness. CANDIDATES chooses Primary Slices or Stack Slices; unsliced layers contribute their whole trimmed region. Similar/Contrast compare with the preceding fragment; Energy/Brightness use Target. Repeats and Chance still apply.

CHOP → SLICE AMP / PROPORTIONAL sets slice Attack, Decay, Sustain and Release. ADR scale to slice length; Slice Sequence additionally fits them to the step duration. Totals above 100% scale together. Envelopes latch at each hit, and sequence handoffs use short complementary crossfades even with zero Attack/Release. This reduces splice artifacts without filling intentional gaps or lengthening short slices.

Character FX

Each pad runs one Character processor after playback. Switching effects recalls that pad's saved bank for the selected effect; it is not an eight-effect chain. MIX blends dry/wet, Pressure and global Mangle add to it, and OUT trims the result. Reverse belongs to playback and Hold/Toggle to Trigger, not Character.

PRESERVE FIELD retains channel order. A discrete source may occupy a wider discrete bus with unused channels silent; Ambisonic sources require an exact order match. Incompatible format/width/bus combinations are silent and flagged. There is no automatic downmix or bus wrap. Spatial sources disable ordinary stereo pan. Route discrete outputs to the intended speakers or a monitoring fold-down; follow Ambisonic output with a matching decoder.

DISTRIBUTE explicitly folds discrete events to a Mono or Stereo object and allocates them within the selected bus. Traversal choices are Sequential, Reverse, Palindrome, Random and Random Cycle. Window/grain/slice events allocate individually; continuous Lanes, Wavesets and Spectral allocate per gesture. Quad/Octo provide room for multiple destinations. Changing routing stops existing voices.

Grains' Stereo Link can unlock position/pitch spray and reverse decisions for discrete stereo. Wider sources remain linked. ACN/SN3D forces Preserve Field and linked reads; distribution never implicitly encodes an Ambisonic field. Shared trim, slice boundaries, envelopes and source movement keep components aligned.

Resample

  1. Open RESAMPLE and select the internal source bus. Recording is after pad processing and master gain, including Fill Hold, but excludes REAPER inputs and downstream external FX.
  2. Choose Record, then use the miniature NEON's PLAY PADS layer to perform loaded cells while recording. A bus-mismatch warning does not reroute those cells automatically.
  3. Stop and audition the completed take. Waveforms and a write cursor are drawn during recording; channel views also apply to captures.
  4. Set Start/End and use CROP TO SELECTION / DISCARD OUTSIDE to keep only the desired audio. This destructively crops the current review, resets its trim/zoom and auditions the result.
  5. Choose an empty Target and Assign Capture to Cell. Playing loaded pads does not change this target. Discard the review before starting another take; already assigned cells remain intact.

On either RESAMPLE pad layer, Shift + pad 1 (REC) toggles recording. A completed review is protected until explicitly discarded. Shift + primary pad 7 crops to selection. Review audition uses bus 1 of a matching layout and is excluded from recording.

Captures preserve the selected bus's channel count/order, including 16-channel 3OA. The limit is 30 seconds or 1,440,000 frames, whichever is shorter—15 seconds at 96 kHz. Changing global output layout stops a take. Stop recording before saving; save a set before cropping if the untrimmed take is needed. Previously assigned cells retain their original audio.

NEON Pages, Encoders and LEDs

On macOS, one Sample Neon instance should have NEON OWNER enabled for direct LED feedback. Do not add a MIDI hardware send back to NEON: feedback addresses overlap controller messages and duplicate routes can create false presses or loops. The plugin still needs an input route, either host MIDI or the Utility's direct-USB mode. Hardware colours distinguish editing pages; the software interface remains grayscale.

For one controller without Tracker, route its native MIDI directly to Sample Neon on all controller channels and enable track monitoring; Utility is optional. Use the Utility chain below when you need bank-aware notes for Tracker or independent identities for two USB controllers.

The hardware's five small status icons retain the physical order One Shot / Toggle / Hold / Loop / Sync; Loop is fourth. Mode + pad cycles trigger behavior. For Sample, Repeat/Slip + pad toggles repeat and Sync + pad toggles tempo sync. Generated methods use their own clock/sustain controls. Primary cell LEDs show loaded audio in red, last played in yellow and currently sounding in white; empty pads are dark. STACK and secondary tools use distinct palettes. Buffer Fill Hold

Hold Shift + the top-right Mode/Censor button, or the GUI's FILL HOLD. It captures recent heard output and temporarily replaces all buses with a deconstructed repeat. Pads and sequencing continue underneath; release crossfades back to their current position. With no recorded history, output stays dry.

FILL SET provides Grab (lookback), Repeat and Breakup. Grab is used on the next press; Repeat/Breakup work live. While held, LOOP controls Repeat and TRAX controls Breakup. Increasing Breakup adds reordered/reversed fragments, ratchets and gaps. All channels share the same read/gate decisions. Resample captures the fill result. RELEASE FILL and KILL provide escape controls. Buffer contents and held state are transient, not saved audio.

Utility Neon MIDI and Tracker

Factory SAMPLE pads use raw notes 0–7 in every bank. s3g Utility Neon MIDI translates these into bank-aware musical notes while keeping page buttons, encoders and other controls separate. For one controller on macOS, put the following in the normal track FX chain:

  1. s3g Utility Neon MIDI: Input HOST MIDI, Control Route TRACKER + SAMPLE NEON, Base Note 36, Output Channel 1. Select the physical NEON as the track input on all native channels, and enable monitoring/record-arm as required by REAPER.
  2. s3g Tracker: use the updated MIDI-through recorder (0.4.1 or newer); set participating lanes, including the recording destination, to CH01.
  3. s3g Sample Neon 32: Base Note 36, EDIT VIEW → ROUTING → MIDI IN → CH 1, and NEON OWNER enabled on this instance only.

Do not remap input channels before Utility, add a parallel raw-NEON route, or return MIDI to the hardware. Keep the physical controller on primary SAMPLER to record pad notes; choosing EDIT encoders in the GUI does not leave that performance page. CHOP/STACK auditions and editing controls are not recorded as Tracker notes or automation. Tracker REC OFF monitors without writing; live Q/MT recording needs running transport.

Ordinary sequencer/keyboard notes address these cells regardless of the visible editing page. Base Note moves the default sequential map; MIDI In accepts Omni or channels 1–16 across all cells. An explicit MIDI In channel gives musical notes priority over overlapping factory controller addresses. The channel filter does not block Utility's private hardware-control messages. Utility owns the performance bank in this chain: use hardware/Utility bank buttons; changing Sample Neon's GUI bank is not a return connection to Utility.

Custom Pad Notes

From Sample Neon 0.37 and Utility Neon MIDI 0.3, choose ROUTING → PAD NOTE MAP in Neon, or PAD NOTE MAP in Utility's title row. The four columns show banks A–D, with pads 1–8 down each column. Click a number to enter a MIDI note from 0 to 127. All 32 notes must be unique; octave names are deliberately avoided because hosts label them differently.

  • PASTE LIST accepts 32 numbers separated by spaces, commas, tabs or line breaks, in A1–A8, B1–B8, C1–C8, D1–D8 order. COPY LIST exports that same order for another instance.
  • FROM A1 fills consecutive notes starting at the draft A1 value (0–96). DEFAULT returns to Base Note plus the cell index, normally 36–67. A custom map uses absolute note numbers and ignores Base Note.
  • Edits remain a draft until APPLY; CANCEL leaves the working map alone. Applying a changed map stops sounding pads/releases held Utility notes, so do this between phrases.

In the Utility → Tracker → Neon chain, enter the map once in Utility and keep Neon's MAP SOURCE on FOLLOW UTILITY (the default). Utility sends the complete map downstream before performance notes; Tracker forwards it without recording it as pattern data. Neon's received grid is read-only. Choose LOCAL and Apply if the instrument should deliberately ignore incoming maps. This is one-way synchronization, not an upstream connection from Neon to Utility.

Both maps are saved in project/plugin state. Neon saves the received map as its fallback when recalled without Utility; connecting Utility again takes precedence in Follow mode. NOTES ONLY still emits the chosen musical notes but omits map synchronization, so use Copy/Paste List to match another instrument manually. The map is global to all banks and both USB controllers, not part of a pad's audio: copying pads, distributing slices, and Reset All retain it. Changing a map does not rewrite notes already recorded in Tracker.

Shift + Sampler toggles hardware velocity sensitivity. Off still sends notes, with fixed velocity 127. Utility pairs the NEON's separate velocity message with the strike and displays NOTE, VEL, AT and VOL; VOL is velocity divided by 127. Sample Neon's ROUTING → VELOCITY → PAD VELOCITY enables dynamic loudness. Aftertouch is separate: the control bridge carries it to Neon, but Tracker does not write it into the pattern.

NOTES ONLY is for another instrument or a note-only recording route. It deliberately drops Neon controls, page/bank feedback synchronization and aftertouch forwarding. It does not convert aftertouch to ordinary MIDI pressure for another instrument. Utility is not a general keyboard MIDI-thru; route a keyboard separately after it. The advanced playback/path/FX settings are saved with Neon but are not all host-automation parameters.

Two USB Controllers

Use Utility Neon MIDI 0.2.1 or newer with both controllers connected by USB and the Smart Link cable removed. Choose USB TWO NEONS and retain the same downstream chain. USB mode opens the inputs directly and ignores duplicate host raw input. Unit 1 starts on A and unit 2 on B for sixteen immediately accessible pads; either can choose any bank. Do not merge two raw inputs and expect independent bank identity.

Each controller keeps its own bank/page, selected cell, modifiers and LED destination. The editor follows the latest press or encoder; both controllers share samples, effects, recorder and Fill Hold. Utility's View selects the displayed unit, Swap USB exchanges assignments, and Relearn USB forgets them. Save the project after assignment. A single controller remains supported; direct USB identity/LED handling is macOS-specific.

Storage, Sets and Reset

StorageWhere audio lives
Project — defaultCollects file-backed and generated pad audio into the saved REAPER project's s3g Samples media directory. Project-relative references are recalled; use REAPER's copy-media option with Save As.
LinkReferences original files. Keep their paths available; generated/pathless audio still needs an embedded payload.
EmbedStores decoded audio in host plug-in state or a .s3gneon set—not in the installed plug-in binary.

The header's policy applies to every pad layer. Project collection needs a saved REAPER project and project-media access; until then collection is pending and imported sources remain linked. Pathless audio and the unassigned resample review remain embedded for safety. Shared PCM is stored once, with a 256 MiB unique embedded-audio limit. Large embedded sets can make saves and host undo snapshots expensive. Missing files can be replaced through Load.

LOAD SET / SAVE SET recall complete sounds, stacks and settings. Load Set warns before replacing current work and starts a new undo history on success; it is not itself undoable. Saving keeps the current history. A set saved in Link/Project mode is not automatically a self-contained sample archive; use Embed when its size is suitable, or carry the referenced media. See the shared storage guide.

RESET ALL requires confirmation; stop recording first. It stops playback, clears all cells and the review take, and resets sound/editing settings, while retaining output layout, Base Note, MIDI receive channel and Neon ownership. Imported files are never deleted. Undo can restore it within this session's history limits; save a set for recovery after closing the project.

Compatibility note: the Character redesign in 0.34 preserves older sources/playback/routing but resets pre-0.34 Character banks and Mangle. Save a separate project copy before migration. The 0.36 Spectral additions default to neutral; sets using new controls require a version that understands them. New state does not make older binaries forward-compatible.
