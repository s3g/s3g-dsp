Macro Effects

Macro effects combine a compact engine with a small set of lane-relationship controls. Use them for fast multichannel shaping when the sound does not require an editable topology network.

Workflow

  1. Choose Macro Delay, Macro Pitch, or Macro Shred in a width that matches the source, then configure the REAPER track and input pins.
  2. Route the result to the main speakers, a direct panner, or a stereo or quad fold-down, then begin playback. Another effect may precede that destination when its build matches the current bus width.
  3. Set the shared sound controls and wet mix before introducing lane variation.
  4. Use spread, deviation, skew, center, or glide controls to coordinate differences across the bus.
  5. Check the full output field and adjust final level before automating the shared controls.

Plugins

  • Macro Delay 8ch/24ch: shared delay, feedback, filtering, and mix controls with lane time, feedback, and level relationships.
  • Macro Pitch 8ch/24ch: shared pitch-shift controls with coordinated lane offsets and movement.
  • Macro Shred Mono/8ch/24ch: pressure, wavefolding, and bounded resonant feedback for voice, microphone, and general audio input.

Relationship Controls

The multichannel builds describe how lanes differ around a shared setting instead of publishing a complete parameter bank per channel. Spread, slope, alternating, and motion controls create repeatable relationships with fewer automation lanes.

Use a topology effect when the result should respond to an editable point network. Use a Macro effect when the main goal is a compact shared sound with controlled lane variation.
