Ambi Effect Displacement

s3g Ambi Effect Displacement 64 is an order-adaptive 1OA through 7OA ACN/SN3D insert. It loads geometry timelines exported by the s3g-mc Displacement Score browser utility and applies them to an encoded ambisonic field through the same listener-body process used by the other Ambi Effects.

Signal Flow

  1. Read the complete active order from (order + 1)^2 channels.
  2. Project the field onto the resolved Icosa12, Dodeca20, or Sphere24 listener body.
  3. Resample the score's 24-point displacement field when the selected body has fewer pickups.
  4. Apply the directional mask, score-driven displacement, and optional distance processing at each pickup.
  5. Re-encode the moving pickup field and blend its correction with the untouched encoded input.

The source and target projections are used as a correction around the original field, so Amount 0%, Mix 0%, or the score's source scene is neutral apart from Output. Geometry, gain, damping, and propagation coefficients ramp across each host block.

Score Files

Use LOAD SCORE to open a version 1 s3g-mc-displacement-score JSON file. The plugin reads up to 64 scenes, uses shortest-path azimuth interpolation, and embeds the parsed score in project state. The browser utility remains the authoring surface; the plugin is a playback and interpretation surface.

The original 24-point score order is preserved when Body is Sphere24. Icosa12 and Dodeca20 sample the same continuous spherical displacement field, so lower pickup counts do not require a different score file. The player also reads raw target radius so its distance mode remains useful when the browser preview was exported with radius normalization enabled.

Free mode advances independently at the selected Rate and continues through Loop or Palindrome playback. Sync mode derives position directly from the host's absolute beat timeline, so playback, seeking, and project reopening return to the same score position instead of depending on an accumulated internal phase.

Distance Interpretation

GAIN treats radius as a capped inverse-distance level law. Radius 1.0 is unity, nearer points can rise to at most +6 dB, and farther points can fall to at most -12 dB.

PHYSICAL keeps that safe gain law and adds relative propagation delay for farther points, distance-dependent air damping, and gradual high-order reduction as points recede. Nearer points are not given negative delay: doing that would require fixed lookahead and host latency. This keeps neutral geometry at zero added latency while still making outward displacement read as physical depth.

Listener Field

The field view provides TOP, SIDE, 3/4, and map cameras plus direct click-drag orbit and scroll zoom. Small source points connect to displaced targets. A radial halo at every target follows pickup energy, making it possible to see which parts of the selected body are receiving the encoded input.

REAPER Routing

Put the plugin after an encoder or other ambisonic process and before the decoder. Set the REAPER track to the complete channel count for the selected order—4, 9, 16, 25, 36, 49, or 64—and keep the plugin pins mapped one-to-one.
