Sample Decks 32

s3g Sample Decks 32 turns two sample stacks into an instrument you can mix, reshape, and pass back and forth. Each deck holds up to 32 layers and uses the playback engines from Sample Neon 32. The crossfader combines their outputs; resampling turns one deck's performance into a new layer on the other.

This first version includes a Reloop Beatpad 2 mapping. It also works entirely on screen. The controller mapping uses the published pad protocol and shared Beatpad transport messages; jog sensitivity, transport variants, and LED colors still need confirmation on the physical Beatpad 2. No replacement firmware is required.

Workflow

  1. Insert Sample Decks 32 on a REAPER instrument track. Leave FORMAT at STEREO for ordinary samples; the main mix uses outputs 1–2.
  2. Route the track's main mix to your stereo monitoring output, or use a matching multichannel output or Ambisonic decoder for spatial material. Drop audio onto Deck A, or choose ADD AUDIO. Multiple dropped files become separate layers. A deck can hold different channel counts; stack playback stays within the selected layer's channel group.
  3. Press Deck A's PLAY, select a playback method, and open A EDIT on the right to shape it in the PLAYBACK editor while keeping A's waveform visible.
  4. Press REC A → B once to begin recording. Press it again to stop. The take appears in Deck B's next empty layer, selected and ready to audition.
  5. Play Deck B and move the crossfader toward B. Change its playback method or effects, then use REC B → A to create another generation.
  6. Use UNDO if you dislike a take or source edit. Save your REAPER project or choose SAVE SET to retain the samples and settings.

Two decks, not two banks of independent pads

A deck has one transport and one active playback method. Its eight performance pads act on that deck. In LAYERS / KEYS → LAYERS, each pad selects and starts a layer, replacing the previous layer launch. PAD BANK exposes layers 1–8, 9–16, 17–24, or 25–32. Changing layers does not change the deck's playback method. Choose KEYBOARD to play pitched chords instead. The Beatpad's physical page for both roles is labeled Sampler.

The left display switches between A WAVE and B EDIT; the right switches between B WAVE and A EDIT. Open A's editor on the right to keep A's waveform visible on the left while adjusting it. The transport and pads below each display always belong to that physical deck: left A, right B. Switching display pages does not switch audio, hardware assignments, or the recording direction.

Choose Playback, Layer Source (or the method's equivalent, such as Mosaic Scope), and Layer in the waveform pane. Stack Navigation and Stack Position stay below the waveform; the Sampler pad role stays in the performance section. The editor starts with its page selector and only the editing controls, leaving more room for the pattern, stack path and source selection. SHOW WAVE brings the matching waveform into the other pane if it is hidden.

A muted cyan-gray title bar identifies Deck A; an orange-gray bar identifies Deck B. An editor's tint follows the deck it controls, while the performance bars below stay tied to the physical left/right decks. The mixer and other shared controls remain neutral gray.

VERTICAL SCROLL runs time from top to bottom; during playback the waveform travels upward past a fixed horizontal playhead. HORIZONTAL SCROLL uses the same behavior with a vertical playhead. HORIZONTAL OVERVIEW and VERTICAL OVERVIEW show a stationary source in either orientation. Use the vertical mouse wheel to zoom; scrolling playback stays centered on its playhead, while an overview zooms around the pointer. Pan a zoomed overview with horizontal wheel/trackpad scrolling, or Shift + vertical wheel. At 1× the entire source already fits. Panning changes only the view, not the sound. Drag the waveform to move the source position. Display choices and zoom are saved with your set or project.

LAYER selects the source you are editing. FOLLOW STACK follows the actual sounding layer and fades between layers during a blend. EDIT LAYER stays with the selected layer. STACK LANES fits all layers into the field: columns with vertical time, rows with horizontal time. Its brightness, individual heads, direction marks, and grain envelopes follow the audio engine. A separate channel menu offers all channels, combined peaks, or channel 1. Start and End define the crop selection.

SET CUE stores the current position; CUE restarts there. Cue and bookmark jumps use a short 5 ms fade-in without moving the stored position. Every channel shares the fade, including multichannel sources with no common zero crossing. STOP stops the deck and clears its effect tail. SYNC sets Time Rate to host tempo divided by Source BPM and restarts from the beginning. It is a rate-matching shortcut, not automatic beat-grid analysis.

Playing chords

Select SAMPLER on the Beatpad 2 itself, then choose KEYBOARD beside that deck's Pad Mode menu in the plug-in. When using only the screen, choose LAYERS / KEYS in that menu first. The eight pads become consecutive chromatic notes rather than layer selectors. The four pad banks cover 32 notes without changing the selected source or playback method. A and B can use different pad roles, so one can play chords while the other launches layers or performs slice interventions.

Press INPUT in that deck's performance header to open its PERFORMANCE INPUT editor on the opposite side. ROOT NOTE is the source's untransposed note and the first key in bank 1; it defaults to MIDI 60 (C4). KEY OCTAVE shifts the keyboard range. KEY VOICES sets the per-deck voice limit from 1 to 16, default 8. Each pad has its own velocity and note release. Changing the bank or pad mode while holding a note does not redirect its release.

For mouse performance, set MOUSE VELOCITY and MOUSE PRESSURE here. MOUSE PADS → HOLD follows the mouse button; LATCH keeps a pad held until you click it again, so you can build a keyboard chord one note at a time. RELEASE MOUSE PADS releases those notes; Stop also clears them. These settings do not alter hardware velocity or pressure. The Scratch and Nudge strips provide the same smoothed jog actions as the hardware: drag left or right. Stack Position below the main waveform provides the equivalent of Shift + jog.

On-screen pads flash for mouse and hardware presses, with a deck-tinted outline while held and a pressure bar along the bottom. A brief tap remains visible even between screen refreshes. Feedback belongs to the pad's original mode and bank, so changing banks does not light an unrelated pad.

All nine methods use Neon's polyphonic gesture engine: each note has independent playback state, readers and envelopes. Pitch follows the method's own tuning behavior; for example Sample changes playback rate, while Motion transposes its cycle. Layer Source, Stack Path, jog gestures, EQ and Character FX remain deck-wide. Pressure modulates the deck's effects using the strongest held pad. Release tails count toward the voice limit, and older released voices are stolen first. Heavy methods and large multichannel stacks cost more CPU as polyphony increases. Stop clears the whole deck.

For applicable methods, LAYER SOURCE chooses Primary, Selected, Velocity, Random / Trigger, or Stack Path. Sample chooses a layer when triggered; Motion, Grains, Stretch, Wavesets, and Spectral can move through layers continuously. Lanes has its own Manual / Stack Path navigation. Cutups uses File Order, and Slice Sequence uses its primary slice map and optional stack-wide mosaic candidates.

Open CUTUPS PATTERN in the deck's editor to draw its sequence as in Neon. All active steps fit in one strip, up to 64. Drag a step's bright horizontal handle vertically to choose its layer; layer 1 is at the top. Drag across steps to shape several at once. The first layer edit switches File Order to Manual while keeping the rest of the generated layer pattern. Hold Option (Alt) while dragging to set each step's source position using the thinner gray handle; this switches Source Order to Manual without changing the layers. The readout identifies the selected step, layer and source percentage. Double-click resets that step's layer address to its default; Option-double-click resets its source position. Pattern edits are saved with your project or set.

The compact STACK PATH graph stays below the main waveform; a larger editor is available on the opposite deck's STACK PATH page. Layer 1 is at the top. Its dot follows the running path. Choose a shape, or click/drag points to make the shape manual; right-click an interior point to remove it. Editing a path shape is distinct from manually choosing the current layer position. FREE playback runs without REAPER's transport. HOST follows host timing and pauses when that transport stops.

Shift + jog takes over stack position without changing the time position. Motion, Grains, Stretch, Wavesets, Lanes, and Spectral blend through the stack; Sample, Slice Sequence, and Cutups select discrete layers. The position remains under MANUAL STACK control after releasing Shift. Choose FOLLOW SOURCE to return to the configured layer source or Stack Path. The on-screen Position slider beside this menu provides the same manual control.

Use the CONTROLS menu when a method has more than one page of controls. Double-click a slider to restore its default. Character processors have their own CHARACTER FX page: Filter, Echo, Space, Shift, Vowel, Punch, Drive, and Crush.

Record, resample and handoff

The RECORD / RESAMPLE source menu chooses DECK OUTPUT, TRACK INPUT, or INPUT + THRU. Deck Output retains the A → B / B → A workflow. For track input, the two buttons become REC INPUT → A and REC INPUT → B: either records into the receiving deck, even when both decks are empty. Select an empty layer on the receiver to choose the destination; if its selected layer is occupied, recording uses the first free layer.

In REAPER, audio must reach the plug-in's input pins: use a track item, an upstream instrument/effect, a track receive, or a monitored hardware input. Choose INPUT 1–2 or another channel group in the recorder. The group's width follows FORMAT: stereo, quad, octo, or 4/9/16-channel ACN/SN3D. Keep the source and Format consistent; Decks does not upmix or convert Ambisonic conventions. Every take uses the output format's channel count, regardless of other layers in the receiving deck. Existing layers retain their original audio and channel counts. When a stack contains several channel counts, playback and Stack Ride use the selected layer's channel group; select another layer to switch groups, with a compatible output Format.

TRACK INPUT records without adding the incoming signal to the plug-in's output. INPUT + THRU also adds the selected input group, unprocessed, to the first channels of the main output; this monitoring is independent of deck levels and the crossfader. Avoid a second monitoring path in REAPER if it would double the signal. Recorded input is taken before Decks' processing and does not include its own deck playback or monitoring output.

Resampling records the sending deck after its EQ, DJ filter, and Character FX, but before its level fader and the crossfader. You can therefore capture a deck while it is inaudible in the main mix. The receiver is not fed back into the recording. Only one take records at a time.

Record is latched, not held. A second press stops it; the maximum take length also stops it automatically. Edit the number beside the recording-time readout to set the maximum from 1 to 120 seconds. The default is 30 seconds, subject to the audio-memory limit.

The live capture thumbnail grows while recording. On completion the take remains as a normal, selected layer on the receiving deck, with Layer Source set to Selected. Press Play to audition it, use CROP TO SELECTION to keep only the wanted section, or DELETE LAYER to discard it. Recording uses an empty layer; it never overwrites an occupied layer.

A missing input bus or channel stops input capture; audio already captured is kept. Connected silence is valid audio and is recorded normally. Changing Format ends the take in its original format. The source/channel choices are locked on screen during a take. Undo/Redo, storage modes and the maximum-duration limit apply to both input recordings and resampling.

Source editing and undo

The SOURCE / CHOP page provides trim, crop, normalization, equal or transient slice markers, and SLICES TO LAYERS. Slice distribution creates new, cropped samples in empty layers of the same deck, leaving the original layer intact. There must be enough empty layers for the whole operation.

Choose EDIT SLICE MARKERS here, or EDIT SLICES in the primary waveform's view menu, to edit the selected layer manually. Click inside the trimmed region to add a boundary, drag an existing boundary to move it, and right-click a boundary to remove it. The endpoints stay fixed. There can be up to 32 slices. Both horizontal and vertical views support editing and mouse zoom. CLEAR MARKERS returns to one full-region slice; it does not delete audio. Choose Follow Stack or Edit Layer to return to waveform scrubbing.

ZERO CROSS refines generated and manually edited slice boundaries using a shared multichannel boundary choice within the trimmed source. Turn it off for exact free placement. Each completed marker drag is one Undo step. Crop, normalize, delete, slice distribution, imports, trims, and completed takes also have internal Undo/Redo. These source edits retain the original PCM without modifying the external file. History is limited to 32 operations and bounded by its retained audio budget; it is not saved with the project. Loading a set starts a new history. Continuous playback/FX parameter tweaks use the host's automation rather than this source-edit history.

Output and spatial material

One plug-in exposes 32 output channels. FORMAT selects stereo, quad, octo, or first-, second-, or third-order ACN/SN3D Ambisonics. The main mix occupies the first 2, 4, 8, 4, 9, or 16 channels respectively. Ambisonic samples must match the selected order. No channel-order conversion or Ambisonic decoding is performed.

STEMS adds separate A and B buses after the main mix when all three buses fit into 32 outputs. For stereo, mix is 1–2, A is 3–4, and B is 5–6. Third-order Ambisonics uses the 16-channel main mix only; two additional 16-channel stems cannot fit.

MIXER / ROUTING contains deck gain, three-band EQ, DJ filter, Slip, and technique routing. Preserve Field keeps source channels linked; Distribute is for discrete sources. Ambisonics forces field-preserving behavior and disables Wavesets, Drive, Crush, and the tape delay mode. These safeguards are not a substitute for checking the source's channel convention.

Beatpad 2 setup

Choose BEATPAD 2 in Setup and select the controller as this REAPER track's MIDI input. Enable record monitoring so MIDI reaches the plug-in. For pad LEDs, add a MIDI hardware output from this track to the Beatpad 2, preserving the original MIDI channels. The pad feedback uses channels 3 and 4, not a single forced output channel. Press REFRESH LEDS after setting up the return path. Feedback also refreshes periodically. Do not route that output back into the plug-in or send it to unrelated devices.

The same roles are available in each deck's on-screen Pad Mode menu. The controls beside it change with the role; INPUT opens further pad options on the opposite side. Page and bank changes do not redirect a held pad's release. Loops and FX toggles stay visibly lit until exited; Stop clears performance overrides. These roles replace the older overlapping pad actions; existing source audio, playback parameters and controller page addresses are retained.

Capture follows Record Source: Deck Output sends to a free layer on the other deck; Track Input records into a free layer on this deck. Timed lengths are fixed when recording arms, using the current host tempo (120 BPM if none is supplied). Take currently finishes and analyzes one recording before arming the next, so it is not gapless. Existing layers are never overwritten. Roll starts a fresh live-history buffer when engaged; another roll becomes available as that history fills.

Jog travel is measured in source time, so a longer file does not make each wheel tick jump farther. Motion, Grains, Stretch, and Spectral use a smoothed source scan and retain their own synthesis. Wavesets changes source at waveform-cycle boundaries; Slice Sequence and Cutups retain their slice/cut timing. These methods intentionally do not all sound like vinyl. The platter response models braking and motor recovery, not a complete physical turntable; sensitivity still needs listening tests on the hardware.

Beatpad 2 transmits pad velocity separately from pad notes. Both velocity-enabled and fixed-velocity operation are supported, along with polyphonic pressure. The decoder allows a short two-millisecond pairing window for the velocity message. Shift + Hot Cue remains the hardware velocity/pressure toggle. Feedback covers all eight pad modes and their Shift pages, following Reloop's Beatpad 2 MIDI map. Loaded layer pads are red, the selected layer yellow, and held pads white; empty layers are dark. Keyboard pads are cyan with yellow root keys. Other performance modes have distinct colors. Actual LED colors and response still need confirmation on your hardware.

For a sequencer instead, choose NOTES / ALL or a specific MIDI channel in Setup. Notes 36 and 37 trigger Deck A and B respectively; note-off stops that deck. CC 16 controls the crossfader. These are deck addresses, not a chromatic keyboard map.

Saving samples

  • PROJECT: imported files, completed recordings, and destructively edited samples are collected into a saved REAPER project's media location in the background. Generated audio is saved as lossless 32-bit float WAV, preserving every channel. Routine saves and mixer edits reuse the prepared paths without rereading or hashing the samples. While collection is pending, if it fails, or before the project has a media location, the loaded audio stays embedded so the save remains complete.
  • LINK: imported samples retain external file paths. Those files must remain available. Generated and destructively edited samples are embedded.
  • EMBED: all loaded PCM travels inside the project or saved set. This is the most portable choice, but produces larger files.

Each changed audio version gets its own verified file; collection never overwrites an earlier take or creates an extra Undo step. Undo and Redo reuse those files. Keep the project's s3g Samples folder intact: older versions may still be needed by REAPER's undo history. With Save As, enable REAPER's copy-media option when moving the project.

SAVE SET and LOAD SET use .s3gdecks files. Choose Embed before saving a set you want to move to another computer. Loading stops both decks. The current document and a new recording are limited to 512 MiB of decoded audio across both decks. The footer shows the amount used. This is an audio budget, not a ceiling on the plug-in's total memory: playback buffers, analysis, waveform peaks and undo history need additional memory.

Import capacity depends on duration, sample rate and channel count, not the compressed or on-disk file size. Audio uses four bytes per sample per channel internally. For example, five minutes of eight-channel audio at 44.1 kHz uses about 404 MiB, leaving about 108 MiB for the other layers and recording. There is no separate import-duration cutoff. On Mac, files are checked against the remaining budget before decoding, and decoded in small chunks. An import that does not fit leaves the existing set unchanged.

Waveforms use cached multichannel peaks, so zooming does not rescan a long recording. Zoom and pan are view preferences: they are retained on the next normal project/set save without creating host undo snapshots. All stack lanes still fit in the view; very narrow lanes show playback cursors without the larger envelope contours. For large sets, completed Project Media collection or Linked storage avoids embedding all audio into every host project-state snapshot. Keep linked files available when reopening the project.

Related instruments: Sample Neon 32 for pad-centered performance, Sample Doubles for two heads over one source, and Sample Circulator for stereo loop circulation.
