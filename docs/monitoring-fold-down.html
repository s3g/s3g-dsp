Monitoring / Fold-down

Monitoring tools audition or inspect wide multichannel tracks without changing the source routing model. Use a fold-down for an ordinary stereo or quad monitor path and a passthrough meter when the original channel layout must remain available downstream.

For a format-first overview that also covers ambisonic Stereo and Head decoders, see Listening on a Stereo System.

Workflow

  1. Choose a stereo or quad fold-down for listening, or Analyzer Meter when the wide bus must pass through unchanged; configure the REAPER track and plugin pins, then set the fold-down input count or meter WIDTH.
  2. Route the stereo, quad, or passthrough output to the intended main speaker or monitor destination, then begin playback.
  3. For a fold-down, set the layout, weighting, and autogain; for the meter, choose the display view.
  4. Confirm that unused lanes are silent where the bus narrows and that the destination receives only the intended outputs.

Fold-down Plugins

  • Output Autogain Stereo: accepts as many as 128 input channels and produces a true stereo output with automatic energy management and 3D placement controls.
  • Output Autogain Quad: produces L, R, RB, and LB quad output from a wide source track.

Metering

Analyzer Meter 64 is a fixed-width passthrough meter with channel-grid, spatial-layout, and energy-over-time views. It is the better choice when the monitor display must not collapse the bus.

Host Routing

The stereo and quad tools expose narrower output buses. In REAPER, inspect the plugin pin connector and enable Zero out unmapped output channels when unused track channels would otherwise pass around a fold-down plugin.
