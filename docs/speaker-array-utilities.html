Speaker Array Utilities

Speaker-array utilities sit after direct panning or decoding. They prepare discrete speaker feeds for the physical system rather than moving sources or changing the artistic mix.

Workflow

  1. Insert fixed-width Output Crossover and Array Calibrate after the direct panner or decoder on a track that matches the rendered speaker bus; for Output Crossover, set the intended subwoofer count before routing its outputs.
  2. Route the final lanes to the corresponding main-speaker and subwoofer hardware outputs, begin playback at a safe level, and confirm channel identity.
  3. Configure crossover and main-speaker high-pass filtering for the physical system.
  4. Set per-speaker alignment delay, then apply trim, mute, and polarity correction.
  5. Verify the calibrated array and leave room-specific settings stable while keeping artistic automation upstream.

Output Crossover

Output Crossover derives low-frequency sends from a Panner Layout speaker array and supports as many as eight subwoofer channels. Use it when bass management belongs to the rendered speaker bus rather than the source or ambisonic field.

Array Calibration

Array Calibrate 16/26/32/64 combines the three room-calibration stages in their intended fixed order: main-speaker high-pass filtering, independent per-speaker alignment delay, then per-speaker gain, mute, and polarity trim. Choose HPF, DELAY, or TRIM in the calibration title bar to edit that stage. STAGE ON/OFF bypasses only the visible stage; the global BYPASS control skips all three while retaining the final output level.

Recommended Order

direct panner or ambisonic decoder
-> Output Crossover (when bass management is required)
-> Array Calibrate (HPF -> delay -> trim)
-> hardware outputs

Choose the fixed-width variant that matches the rendered array. Keep artistic automation upstream; calibration settings should normally remain stable for a given room and output interface.
