Matrix Upmix 64

s3g Matrix Upmix 64 distributes an existing stereo or multichannel mix across an equal or larger speaker format. Each matrix cell controls how much of one input reaches one output, so the complete routing remains visible and editable.

Use it for straightforward jobs such as Stereo → Quad, Quad → Octophonic, or Octophonic → Double Ring 32. It does not synthesize new sources or decode Ambisonics; it routes and weights the channels you already have.

Workflow

  1. Set the host track and plug-in pins to 64 channels.
  2. Choose the source under IN FORMAT and the speaker array under OUT FORMAT. The output format must have at least as many channels as the input.
  3. Choose a starting map from PRESET, or use AUTO FILL for other format combinations.
  4. Click matrix cells to add or select connections. Drag vertically inside a cell, or use GAIN in the Selected section, to set its level. Right-click a cell to delete it.
  5. Use LAYOUT to confirm that channel numbers and speaker positions match the destination system.
  6. Set OUTPUT GAIN for suitable headroom, then route the active outputs to the corresponding speakers or monitor path.

Presets

A factory preset chooses the input format, output format, and all required matrix connections. You can edit any preset after loading it.

Preset groupResult
Stereo → Quad RepeatCopies Left to the left front and rear, and Right to the right front and rear.
Stereo → Quad CrossKeeps the front pair in place and sends each rear speaker the opposite stereo channel.
Stereo → Quad DifferenceKeeps Left and Right in front and places stereo difference signals in the rear pair. Purple cells show the fixed opposite-polarity routes used by this preset.
Stereo → 5.0 / 7.0 SpreadSpreads the stereo pair across front, center, side, and rear positions.
Quad → Octophonic / Ring 12 / Ring 16Assigns each Quad channel an equal, adjacent group of output speakers in spatial order.
Quad → Double Ring 16Assigns every Quad channel two speakers on each height ring.
Octophonic → Ring 16 / Ring 32Expands each Octophonic channel to an equal group of nearby output speakers.
Octophonic → Double Ring 16 / 32Distributes every Octophonic channel evenly across both height rings.

The Quad and Octophonic ring presets use every output once and divide the outputs evenly between inputs. Connections stay in adjacent spatial groups instead of crossing around the ring.

Auto Fill

Use Auto Fill when there is no factory preset for the selected formats. Choose a recipe, adjust its options, and press APPLY. The generated connections can then be edited like any other matrix cells.

RecipeGenerated distribution
RepeatRepeats the complete input order across additional outputs. Only complete rounds are used, keeping the number of connections equal for every input.
Spatial MatchPrefers nearby outputs on the same side of the speaker layout.
CrossPrefers outputs on the opposite side for the added connections.
All TiersUses every output and distributes connections across all available height tiers.

ROUTES / INPUT sets the desired number of connections for Spatial Match and Cross. Repeat uses REPEAT ROUNDS. WEIGHT SHAPE can keep the gains Flat or emphasize the Center, Edges, or a gradual Taper within each generated group.

Understanding Gain

Each percentage belongs to one connection. It is not a shared 100% budget for the row or column. A 100% cell sends that input to that output at unity gain, so three 100% cells in one row are three unity-gain copies. Their displayed total is 300%, but each route is still valid.

  • 100% = 1.000 = 0 dB
  • 70.7% = 0.707 ≈ −3.0 dB
  • 57.7% = 0.577 ≈ −4.8 dB
  • 50% = 0.500 ≈ −6.0 dB
  • 25% = 0.250 ≈ −12.0 dB

For an equal-power fan-out, use 70.7% for two destinations, 57.7% for three, 50% for four, or 35.4% for eight. NORMALIZE INPUTS calculates this balance for every active row while preserving any intentional differences between its cells.

Several inputs can also meet in one output column. Their audio is summed, so the result may become louder or clip. LIMIT OUTPUTS reduces heavily loaded columns, but it is not a peak limiter: closely related signals can still add together strongly. Use OUTPUT GAIN to leave final headroom.

NORMALIZE INPUTS manages how each source is spread; LIMIT OUTPUTS manages how several sources meet at one destination. Both commands update the visible cell values.

Formats and Speaker Coordinates

The format menus include common surround and height formats, rings and double rings through 64 channels, Cube, LPAC, Dodecahedron, Icosahedron, Dome, SRST, Sphere, and Custom AED layouts.

AED means azimuth, elevation, and distance. In the s3g coordinate view, front is 0°, listener-left is +90°, listener-right is −90°, and rear is ±180°. Press EDIT IN or EDIT OUT to make a custom layout, choose its channel count, and enter the coordinates for each numbered speaker. The node numbers define the channel order.

Tier Rings Layout

Tier Rings shows the input and output layouts from above. The lowest speaker tier is the outer shape, higher tiers move inward, and a directly overhead speaker appears in the center. Circular, rectangular, and irregular tiers keep their general shape.

Click an input node to select its matrix row or an output node to select its column. The nodes on the opposite side change color and size to show the selected channel’s connections and gains. POP OUT keeps the layout visible in a separate window; DOCK returns it to the main plug-in window.

Large Arrays and Recall

For large arrays, the matrix reduces the number of visible labels to prevent overlap; every crosspoint remains available. Selecting a cell or a Tier Rings node identifies the exact input and output.

SAVE stores the complete matrix, formats, gains, and custom speaker coordinates. LOAD recalls a saved setup. The host session also stores the current plug-in state.
