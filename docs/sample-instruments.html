Sample Instruments

The Sample family turns loaded or captured audio into playable instruments. Choose by the kind of source movement or performance structure you need; each linked guide covers the complete controls, routing, and state behavior.

Workflow

  1. Insert the required output format—stereo, multichannel, or Ambisonic—and match the REAPER track width to its fixed output.
  2. Establish monitoring before loading audio. Route ordinary multichannel outputs to speakers, a direct panner, or Output Autogain Stereo/Quad; follow Processor Ambi Grain with an ambisonic decoder.
  3. Load the source files, or route live input to Sample Circulator or Sample Rings for capture. Choose the storage policy below for file-backed sources.
  4. Use the instrument guide for its source regions, timing, MIDI, processing, and routing controls, then audition and save the project.

Sample Storage

ModeBehaviorBest use
PROJECTCopies the unchanged source into the saved REAPER project's s3g Samples media directory and stores a path reference.Normal sessions; the default
LINKReferences the original file without copying it.Stable externally managed media
EMBEDStores decoded floating-point audio in CLAP state.Self-contained exchange

PROJECT requires a saved REAPER project and supported project-media access. Until both are available, collection remains pending and the current source stays usable. Copies are content-verified and reused when the source is unchanged. Registered media follows a REAPER Save As only when a copy-media option is selected.

LINK keeps state small but requires the original path to remain valid. EMBED is portable, but decoded audio can be much larger than the source file and may enlarge host undo snapshots; prefer PROJECT for routine work. Missing paths remain available for later relinking. Generated Slicer material can be written as project media, while live captures remain embedded.

Sample Player, Doubles, Wavesets, Motion, Lanes, Grains, Slicer, and Rings use this three-mode policy. Sample Circulator is the exception: it always embeds its two stereo loops, with a capacity of approximately 32 seconds per loop.
