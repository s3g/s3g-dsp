Sample / Loop Instruments

Sample and loop instruments load audio files as their source. The Processor Loop family creates discrete eight-channel playback structures; Processor Ambi Grain treats a loaded ambisonic file as one locked encoded field.

Workflow

  1. Choose an instrument and, for Processor Ambi Grain, select the source order. Set the REAPER track to the required channel count, then insert the plugin.
  2. For Processor Loop or Processor Multi Loop, route the eight output lanes to the main speakers, a downstream direct panner, or Output Autogain Stereo/Quad for fold-down monitoring. For Processor Ambi Grain, follow it with an ambisonic decoder.
  3. Load the source file or files and confirm that the expected channels appear.
  4. For a loop instrument, set the source assignment, loop region, playback, and lane relationships. For Processor Ambi Grain, set the shared grain controls.
  5. Audition the result through the established output path, then keep the source files with the project or in a stable media location.

Loop Family

  • Processor Loop: one loaded file distributed through an eight-channel loop instrument.
  • Processor Multi Loop: as many as four loaded files assigned across an eight-channel loop structure.

Ambisonic Granulation

Processor Ambi Grain loads 1OA, 2OA, or 3OA ACN/SN3D media. Grain time, direction, rate, and envelope remain shared across all active channels so the encoded image stays coherent.

Files and Project State

Loaded-media instruments depend on external source files. Keep those files with the project or in a stable media location, and confirm the source path after moving a session to another computer.
