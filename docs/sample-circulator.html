Sample Circulator 2

s3g Sample Circulator 2 is a compact file-or-capture stereo loop instrument descended from the original CRCLTR v1.0.1 Gen/Oopsy firmware engine. New instances open in the flexible Dual model, while Classic remains available for the original loop relationship.

Load a mono or stereo file into either slot, or replace, overdub, and punch its live stereo captures; choose an editable window, direction, rate, and join for each loop; then move between them manually or with periodic, ramped, stepped, or random motion. It is intentionally simpler than Sample Rings: two stereo loop slots, one crossfade, and stereo-only I/O.

Workflow

  1. Insert Sample Circulator on a stereo REAPER track.
  2. Route the stereo output to the main speakers or stereo monitor path, set Blend toward the loops, and begin playback. Another effect may precede that destination when its build matches the stereo bus.
  3. Press Load A or Load B, or drop a file directly on the matching waveform lane. Dropping two files together assigns the first to A and the second to B. For live capture instead, route the source to the plug-in's left and right inputs.
  4. Choose Loop 1, Both, or Loop 2 with Record Target, then choose Replace, Overdub, or Punch.
  5. Set Record to RECORD and hold it for the desired capture time, or hold MIDI C2.
  6. Return Record to Idle to close the loop and restart its playhead.
  7. Drag the S and E markers on either waveform, or use the matching sliders, to queue each loop's next start and end; then choose direction, rate, and Seam or Duck join.
  8. Choose a Crossfade Motion and Fade Shape, then set Position manually or set the automated motion Rate.
  9. Balance the live source and loop crossfade with Blend.

A record hold shorter than 100 ms is discarded without changing an existing loop. The first 100 ms is kept in a pre-roll buffer, so a valid hold retains its beginning.

Waveforms and MIDI Buttons

The waveform panel draws normalized grayscale left and right envelopes for loaded files and embedded captures, so quiet material remains legible. Mono files are duplicated to both stereo lanes. Grab either thin S or E marker to edit the same Start or End parameter shown by the sliders. During playback, the solid markers move immediately while dashed markers retain the active window and NEXT WRAP shows that the edit is queued. The reader finishes its current pass, adopts the latest window at wrap, and uses a short boundary handoff to prevent a click or cursor seek. An edit made while stopped is ready before playback resumes.

Files decode in the background. During playback, a replacement becomes audible only after the complete loop is ready. Files longer than the 32-second slot capacity are truncated; sample-rate conversion preserves their duration and pitch up to that limit.

The vertical graph at the left borrows the Sample Lanes path display and follows the waveform order directly: cool blue A is at the top, warm amber B is at the bottom, and violet marks the region where both loops contribute. Its gradient changes with the selected gain law. A horizontal line and center handle show the current mix, while the arrow shows travel toward A or B. In Manual mode, drag the graph vertically to set Position directly.

Motion choices are Sine, Trapezoid with endpoint holds, bounded Random Walk, constant-speed Triangle, repeating A-to-B and B-to-A ramps, Sample & Hold, and Square. The clock follows Loop A's selected window and rate when available, falls back to Loop B when A is empty, and uses a neutral one-second cycle when both captures are empty.

Fade Shape is independent of motion. Equal Power retains the original law; Linear is constant-sum; Wide and Tight change the shared region; Smooth eases both ends; Full Overlap brings both loops to unity at center; Deep Dip strongly attenuates the center; Plateau holds a stable equal-power blend; and Cut makes a narrow, smoothed handoff. These shapes apply only to the A/B circulator mix: each loop's Seam join retains its own short equal-power End-to-Start crossfade.

Loop Models

Dual gives both slots complete independent captures with their own start/end window, direction, rate, and join. Each slot can contain approximately 32 seconds at the current session sample rate.

CRCLTR Classic retains the original relationship: Loop 1 reads the first half of its capture while Loop 2 reads the complete capture. Each loop still uses its current Start, End, direction, rate, and Join controls. Older CRCLTR sessions select Classic automatically.

Sample-Rate Behavior

Rates, timing constants, and recording behavior adapt to the session sample rate, so loop durations remain consistent across sample rates.

Storage and Recall

Sample Circulator stores both stereo loops inside the host project whether they came from files or live capture, so reopening a session does not depend on the original files remaining in place. If the session sample rate changes, the loops are resampled during recall to preserve their duration.

Older CRCLTR sessions reopen in Classic mode. The loops, playback windows, directions, rates, joins, crossfade settings, and play state otherwise return with the project.
