s3g-dsp

s3g-dsp is a collection of CLAP plugins for spatial audio, ambisonics, multichannel processing, and synthesis on macOS, together with standalone apps built from selected shared processors.

The collection emphasizes predictable multichannel routing, compact automation, and clear multichannel control models.

The packaged pre-release supports REAPER on Apple silicon Macs only (arm64—M1, M2, M3, M4, or newer). It does not contain Intel-compatible or universal binaries.

Start Here

  • Install the pre-release plugins to use the packaged macOS CLAP collection. The included Install s3g-dsp CLAPs.command handles canonical filenames and recognized older aliases.
  • s3g Tracker documents the source-build MIDI tracker preview: polymetric lanes, sample-offset sequencing effects, pattern and Song workflows, timing warps, Live Code, and per-track REAPER routing.
  • Processor Feedback Shift documents the 0.18.1 source-build release candidate: an eight-node feedback ecology with paired scenes, high-density virtual patch splicing, shared s3g processor inserts, in-network aux processing, and stereo, quad, or direct-eight output.
  • Standalone Apps documents applications that run selected s3g-dsp instruments without REAPER, beginning with s3g No Input Mixer.
  • Build from source to compile the collection locally.
  • Listening on a Stereo System explains how to monitor ordinary multichannel and ambisonic sessions through two loudspeakers or headphones.
  • Multichannel covers effects, fold-down, metering, direct panning, bus mixing, and speaker utilities for ordinary channel lanes.
  • Ambisonics separates encoders, decoders, effects, and utilities for ACN/SN3D workflows; Listener Mode explains how selected tools respond to their own encoded field, and Parameter Surface explains preset-cell interpolation for performance and automation.
  • Instruments covers loaded-audio and synthesis CLAP instruments, including the synthesized drum family.
  • References provides historical, technical, and conceptual background for the documented tools and workflows.

Release Status

s3g-dsp is pre-release software. Plugin names, parameters, included bundles, and saved states may change. The macOS package installs the complete manifest-listed CLAP set, including fixed-width variants for several plugin families.

When installing or upgrading, use the packaged installer so bundle filenames match the family-first names shown in the host. The migration preserves the stable CLAP IDs used by saved projects. Run it with --dry-run to preview changes or --canonicalize-only to rename verified installed binaries; recognized legacy aliases are moved to a timestamped backup rather than deleted.

For packaged and manual installation, see Install s3g-dsp CLAP Plugins.

Using the Collection

  • Match a fixed-width plugin to the REAPER track width before setting its pin routing.
  • Use Multichannel tools for ordinary audio lanes or speaker feeds and Ambisonics tools for encoded ACN/SN3D fields.
  • Follow an ambisonic instrument or encoder with field effects, utilities, and a decoder configured for the same order.

Related Projects

s3g-mc is the sibling REAPER package for scripts, JSFX, process guides, and multichannel workflow tools. It can be used alongside s3g-dsp or independently in matching macOS + REAPER sessions.

s3g-max is the related Max/MSP package for .mxo externals, help patches, V8UI displays, and Max package workflows.

s3g-clap-max provides a Max object for loading CLAP plugins, allowing the CLAP plugins in s3g-dsp to be used with Max.

s3g-rnbo-clap is the separate wrapper project for RNBO/Max-generated C++ exports. It follows the same CLAP release workflow but is not required to build or use s3g-dsp.
