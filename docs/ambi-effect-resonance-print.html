Ambi Effect Resonance Print

s3g Ambi Effect Resonance Print 64 listens to a complete 1OA through 7OA ACN/SN3D field, captures a compact directional modal fingerprint, and turns that fingerprint into an excitable resonant body. The result is closer to freezing the field's resonant identity than freezing its spectrum: transients and new material can continue to strike the learned modes.

Workflow

  1. Place Resonance Print on a correctly routed ambisonic track and match its ambisonic order to the incoming field.
  2. Follow it with an ambisonic decoder. Additional Ambisonic effects may be placed before the decoder when their supported order and channel count match the field.
  3. Begin with Local topology, a short Decay, moderate Drive, and reduced Mix or Output.
  4. Play a harmonically useful passage and press Capture. The completed print remains bypassed.
  5. Press Apply Print, then use Apply / Bypass Print to compare it with the input without clearing the capture.
  6. Shape the result with Transpose, Harmonic Pull, Decay, topology, and the directional mask. If GOV or SAFE remains visible, reduce Drive, Mix, or Output.

Signal Flow

  1. Decode the active order onto the selected Icosa12, Dodeca20, or Sphere24 auditory body.
  2. While Capture is active, analyze overlapping 4096-sample Hann-windowed frames at every pickup.
  3. Retain the strongest stable local peaks per pickup and estimate one shared fundamental hypothesis for the complete field.
  4. When Apply Print is enabled, excite a bank of damped sinusoidal modes at each pickup from the live field.
  5. Apply local, cross, diffuse, or roaming body relationships and the directional wet mask.
  6. Re-encode only the processed correction and blend it over the untouched ambisonic input.

The modal bank uses second-order resonators rather than long per-pickup impulse responses. It therefore adds no fixed host latency and remains practical at the 24-pickup Sphere body. The reported tail follows the longest transformed modal decay.

What the Print Contains

A print stores the captured body, a field-level fundamental estimate and confidence, and up to twelve frequency, amplitude, and stability values for each pickup. It does not store captured audio. A full print is only a few kilobytes and is embedded directly in CLAP project state, so reopening a session restores the learned body without an external media file. The editor's SAVE and LOAD actions use that same complete CLAP state, so a saved Resonance Print preset includes the print, its applied or bypassed state, the controls, and the camera view.

Capture lasts from 0.25 to 3.0 s. Starting a capture immediately bypasses print processing; the previous model remains stored while analysis runs, and the completed capture remains bypassed. Use Apply Print only when ready, then Bypass Print to A/B the unprocessed input without deleting the model. Clear Print is the destructive action and also cancels an active capture. Changing ambisonic order or auditory body during capture cancels that capture so one print cannot accidentally combine two projection geometries.

Auditory Body

AUTO uses Icosa12 for 1OA and 2OA, Dodeca20 for 3OA, and Sphere24 for 4OA through 7OA. The three bodies can also be selected explicitly. If playback uses a different body from the captured print, each current pickup follows the nearest captured direction; the print remains portable instead of being discarded.

The field view shows pickup input energy, print strength, and directional-mask attenuation. TOP, SIDE, and 3/4 provide repeatable cameras; dragging the field creates a custom orbit. The dashed target shows the mask direction. Mask elevation follows the ambisonic convention: 0° is the horizontal plane, +90° is the upper +Z pole, and -90° is the lower pole. Select a pickup to edit its persistent Tune and Decay trims. These twenty-four slots and the camera state remain in project state even when a lower-density body is active.

Level Safety

Captured amplitudes are normalized per pickup. Before the live decoded field excites the resonator banks, a linked governor gives the complete auditory body one shared excitation budget with a 0.25 peak target, immediate reduction, and a 250 ms recovery. It affects only resonator excitation: capture analysis and the dry HOA path remain untouched. When it acts, the title status reports GOV -x dB.

Live tuning uses a physical-time modal-frequency glide plus continuous recurrence-coefficient interpolation instead of coarse coefficient jumps. Amplitude-dependent pole damping begins well before an unstable state, followed by a smooth remote state knee; only non-finite states are reset. As a result, Transpose and related tuning controls can move smoothly while long modes contain energy.

The final gain stage follows the Ambi Encoder Modal safeguard order: the blended HOA field passes through smoothed Output gain and then one linked -1 dBFS guard with immediate attack and a 300 ms release. It remains available during print bypass and with no print, so positive Output gain cannot expose an unprotected dry path. Steady signals below the ceiling request unity gain; after an overload the guard recovers smoothly. The shared scalar preserves spatial relationships. When it acts, the title reports SAFE -x dB.

Applying a print can still cause strong tonal reinforcement, so capture never applies it automatically. Start with reduced Mix or Output before the first application. If GOV or SAFE remains active continuously, lower Drive, Mix, or Output: the safeguards prevent overload, but sustained gain reduction is an audible dynamics process.

REAPER Routing

Place Resonance Print after an encoder or encoded recording and before the final decoder. Set the track to the complete channel count for the selected order—4, 9, 16, 25, 36, 49, or 64—and map the plugin pins one-to-one. Begin with Local topology, Mix near 55%, and a short decay; capture a harmonically rich field, then raise Harmonic Pull only if a more explicitly pitched body is wanted.
