Ambi Encoder Acid

Ambi Encoder Acid is a monophonic sixteen-step bassline instrument whose filtered body, resonant edge, and delayed wake occupy related positions in a first-, second-, or third-order ACN/SN3D field. Each step can set pitch, gate, accent, and slide while the complete line traces a configurable path through space.

This instrument is currently a source-build preview. Configure with -DS3G_BUILD_CLAP_PLUGIN=ON -DS3G_BUILD_FUTURE_COMPONENTS=ON to build s3g Ambi Encoder Acid 16. It has no audio input and is intentionally excluded from the current packaged pre-release manifest.

Workflow

  1. Set the track to 16 channels, insert s3g Ambi Encoder Acid 16, and choose 1OA, 2OA, or 3OA from ORDER.
  2. Follow it with an ambisonic decoder.
  3. Choose a factory pattern, then drag the note bars and switch each step’s G, A, and S buttons for gate, accent, and slide.
  4. Use INT for the internal tempo or HOST to align every step to the transport’s absolute beat position.
  5. Shape the oscillator and resonant filter, then set the spatial path with AZIM, TURNS, ELEV, and SPREAD.
  6. Raise WAKE for trailing spatial taps. Add Listener Mode only after the authored line and field are working on their own.

Signal Flow

  1. The internal or host-synchronized clock selects one of the active steps. Its note offset, gate, accent, and slide state become the current performance gesture.
  2. A band-limited saw-to-pulse oscillator follows the root note and step offset. A tied slide moves continuously to the next gated step instead of retriggering the complete envelope.
  3. The oscillator passes through a driven resonant filter. The main filtered body and a brighter resonant edge remain separate spatial components.
  4. The step index maps to a path around the selected azimuth and elevation range. The body follows that point while EDGE advances or trails the resonant component.
  5. Four delayed edge taps retain earlier path directions, creating the spatial wake before the selected ambisonic order is encoded.
  6. The optional Listener reads the completed pre-output field. Final OUTPUT gain and the linked safety limiter remain outside that auditory loop.

Editing the Note Line

Drag vertically in a step’s note area to set a semitone offset from ROOT. The note name and signed interval update together. G enables the gate, A applies the shared accent amount, and S ties pitch into the next gated step. A disabled gate becomes a rest even if its stored pitch, accent, or slide values remain visible.

LENGTH limits playback to the first 1–16 steps without erasing the remaining cells. DIVIDE sets 1–8 steps per beat. With CLOCK on HOST, starts, seeks, loop wraps, and tempo changes follow the absolute host beat instead of maintaining a second free-running clock. TEMPO is used only by the internal clock.

Acid Voice

WAVE moves from saw toward pulse, and PULSE changes pulse width. CUTOFF sets the filter’s base frequency; RESO emphasizes its edge; ENV sets the filter sweep in octaves; and DECAY controls how quickly that sweep falls. ACCENT increases level and extends the filter gesture on accented steps, while DRIVE adds saturation before spatial encoding. SLIDE sets the continuous pitch-transition time.

Spatial Path and Wake

AZIM centers the line’s horizontal path. TURNS sets its direction and number of rotations across the active pattern, while ELEV adds a vertical wave. SPREAD blends from a front-centered source toward that authored path. The body follows the current point and EDGE rotates the filter edge ahead of or behind it.

WAKE adds four progressively quieter delayed copies of the resonant edge. Each copy keeps a previous step direction, so increasing WAKE T stretches the line’s recent movement into a wider audible trail rather than adding a mono echo after encoding.

Listener Mode

LISTEN uses the shared eight-pickup Cube listener described on the Listener Mode page. FOLLOW favors recently active directions, COUNTER favors their antipodes, and BALANCE favors quieter regions. OFF is the exact open-loop reference.

Listener decisions occur only at step boundaries. AMOUNT can bend the next authored direction toward the selected preference and apply a small filter-cutoff bias; it never rewrites pattern pitch, gates, accents, slides, or clock decisions. MEMORY sets how quickly the directional analysis forgets the recent field.

Patterns and Presets

The title menu supplies twelve patterns: CHROME BURROW, VENOM CIRCUIT, SUBWAY TEETH, NEON CENTIPEDE, RUSTED APSE, MERCURY STAIRS, BLACKLIGHT MOSS, QUARRY SIGNAL, NIGHT FOUNDRY, STATIC ROOT, HOLLOW RELAY, and GLASS WORM. Choosing one replaces the sixteen step cells. LOAD restores a saved plugin state while preserving the current OUTPUT trim, SAVE writes the complete state, and RANDOM creates a bounded pattern variation.

Limits

Acid is one monophonic line rather than a polyphonic MIDI instrument and accepts no audio input. Its wake is a compact four-tap history of the filter edge, not a general-purpose delay. Listener Mode responds to the generated field but stays deliberately bounded; use downstream ambisonic processing when the complete scene needs larger rotation, reverberation, or decoding changes.
