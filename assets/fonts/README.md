# Bundled UI Fonts

## Active Macro Delay font

`FiraCode-Regular.ttf` is the static TrueType build from Fira Code 6.2.

- Upstream: <https://github.com/tonsky/FiraCode>
- SHA-256: `5992ab9640e2df491b2f609467b1de60e8bc39b2c28db184342a0592d98f6117`
- License: `FiraCode-LICENSE.txt` (SIL Open Font License 1.1)
- Default zero: slashed

## Retained comparison font

`SourceCodePro-Regular.ttf` is the static TrueType build from Adobe's Source
Code Pro release `2.042R-u/1.062R-i/1.026R-vf`.

- Upstream: <https://github.com/adobe-fonts/source-code-pro>
- SHA-256: `74bd80d3e42a08517cd7e1108ba3d86f2da29ac0f3065be95e0357956ab9db37`
- License: `SourceCodePro-LICENSE.md` (SIL Open Font License 1.1)

Keep the static font file pinned. Replacing it with a variable build or a
different release can change glyph metrics and cross-platform GUI layout.
