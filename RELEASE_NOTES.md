# s3g-dsp 0.8.0-pre

Apple silicon macOS CLAP collection and optional No Input Mixer standalone pre-release, prepared August 21, 2026.

## Assets

- `s3g-dsp-macos-clap-0.8.0-pre.zip` — 129 CLAP bundles containing 135 plug-ins for REAPER
- `s3g-no-input-mixer-app-macos-arm64-0.8.0-pre.zip` — standalone No Input Mixer application

Both archives contain arm64 binaries for Apple silicon Macs (M1, M2, M3, M4, or newer). They are not compiled for Intel Macs and are not universal binaries. The standalone app currently requires macOS 15 or newer and is distributed separately from the CLAP collection.

## Highlights

- Adds **s3g Sample Rings 8** as the unified successor to Processor Loop and Processor Multi Loop, which are retired from the active build and installer. Four independent slots can load files or capture as many as eight input channels from DAW routing and upstream effects, with Replace, Overdub, Punch, free/beat/bar quantization, explicit capture width, and Loop/Input/Both monitoring. Every usable source channel becomes a concentric loop ring—up to eight per slot and 32 total—while eight read heads move through radius and loop angle without baking files into a composite; two-tone muted teal boundary rings separate populated A–D file bands. Fixed, Outward, Inward, Bounce, Sine, stepped, seeded-random, and Manual radial paths combine with Free, paired, quad, or Field8 formations; formations link radial travel but preserve the eight independent Unison, Canon, Fan, Ratio, Shear, Orbit, Drift, or Manual angular clocks. Bipolar Angle Amount mirrors relationship ordering or modulation polarity around Head Pivot, while each Manual head has a signed −4x to +4x angular rate with a true stop at 0x and a wrapped phase displayed from −180° to +180°. Ring Blend equal-power-crossfades adjacent rings even when their file clocks differ, and its thin visual bridge now appears only while both reads are audible. Playback Rate is the common angular/radial master, while Radial Ratio scales a stable eight-second field cycle instead of borrowing the first source duration. Radial Reverse reverses every moving radial path and disables itself for Fixed Ring, and Angular Reverse independently reverses audible and displayed movement around the rings. Each slot retains its own loop window, varispeed, pitch-preserving stretch, pitch, wrap nudge, gain, and reverse state. The 1356-by-820 editor draws all channel waveforms as their actual rings, supports direct polar editing, and adds explicit selected-head Mute/Solo controls over the automatable Head Mask. Capture, seam, MIDI, and direct/quad/stereo output controls remain visible. The shared Project/Link/Embed source contract now defaults file loads to content-verified, duplicate-reusing project-media copies registered with the exact owning REAPER project; unsaved projects remain pending, Link retains the external path, Embed stores PCM, and live captures always embed. State version 6 migrates version 5 file references to Link while retaining embedded captures.
- Adds **s3g Sample Motion 2** and **s3g Sample Motion 32**. Eight trajectories cover Hover, polarity-reflected Mirror, seeded Drunk, alternating Zigzag, one-way Forward/Reverse, a stepping Moving Loop, and non-inverting Round Trip reading. Normal `1x` follows ordinary source speed, with absolute Hertz available. Continuous, Packets, and nested Motor articulation share four envelope shapes. An allocation-free four-lane event layer adds Freeze, naturalized Iterate, short random-position Pulser packets, contiguous grouped Doublets, accelerating/decaying/shrinking Bounce, and Routed Iterate with Clock/Packet/Turn triggering and Cut/Layer playback. Motion 32 can allocate at note, turn, or segment boundaries, including per-turn voice reassignment, event-time routing, and optional adjacent-destination avoidance. The Sample-family editor adds asynchronous load/drop/clear, waveform S/E/L editing, zoom/pan/fit, presets, a numbered Source Motion → Sound → Output hierarchy, one exclusive Sound selector, process-specific source/motion relationship readouts, trajectory scope, routed compositor flags, and host-correct automation. Version 0.4.3 adds path-coupling classifications, trigger-dependent control guards, and direct Packet Rate access for Event sounds; 0.4.2 introduced the explicit hierarchy and source-role readouts; 0.4.1 corrected the Motion parameter range so Moving Loop and Round Trip are selectable from both the editor and host parameter surfaces.
- Adds **s3g Sample Lanes 2** and **s3g Sample Lanes 32**, four-file loop instruments with one normalized two-dimensional read head. Independently sized sources occupy four visible lanes; shaped Down, Up, Triangle, Sine, stepped, seeded-random, and editable manual breakpoint paths either equal-power crossfade or click-smooth jump between them. Random playback uses the exact eight-step path drawn in the scope, while Manual supports click-to-add, drag-to-shape, and right-click deletion of up to 16 state-persistent points. Each lane adds independent Speed, pitch-preserving Stretch, and visibly rotating signed wraparound timing Nudge. Restrained dark-gray waveforms now sit behind bright, dark-haloed live read-head points so dense source material cannot obscure position. The wide two-column editor moves timing, transport, and path toolboxes beside the source displays and reduces the native height to 724 pixels. The 32-channel edition accepts one-to-sixteen-channel files and separates channel-locked **Preserve Field** routing from explicit mono/stereo object folding and shared 2–32-channel distribution. A Motion-style Routing tab now keeps this topology off the normal voice page and exposes active output count as a categorical 02–32 menu.
- Adds **s3g Sample Grains 2** and **s3g Sample Grains 32**, a non-ambisonic four-file granular family built on the same lane waveform, breakpoint path, MIDI, and Project/Link/Embed contracts. Scan, Freeze, Cloud, and Slice choose source time; Parzen, Sine, Hann, Triangle, and Gaussian shape each grain; and a separate Regular/Scatter event clock applies Ordinary, loudness-Sorter, Stutter, progressively accelerating Shrink, or source-time-related Doublets. Direct scheduler extensions add per-event Size and Level Variation, continuously variable Scatter depth, earlier/later Envelope Skew, Behind/Around/Ahead Position Bias, Scan- or Grain-clocked source-field advance, and a ±48-semitone Pitch Shift that changes grain transposition without changing scan speed, density, or grain duration. Version 0.4.1 restores MIDI-note conditioning of Scan Speed around Scan Root—doubling per octave in either rate basis—while keeping Grain Pitch Shift independent of the played note. Doublets Amount now sets pair probability from none to every event. Grain advance steps the existing visible path instead of creating a hidden lane order, keeping seeded Random and editable Manual behavior identical between scope and audio. Version 0.4 intentionally replaces the earlier Grains parameter/state contract: Loop Join, Manual Lane, Jump Slew, fixed Alloc Clock, and the twelve host-only per-lane Speed/Stretch/Nudge controls are removed. The breakpoint editor is the sole manual-path representation, direct grain choice needs no slew, and allocation always occurs per grain. Gate, finite one-window One Shot, and Toggle replace the formerly redundant Auto/Gate trigger menu. Its gap-free 1280-by-932 editor gives every slider a consistent 24-pixel row pitch: Source Scan, Grain Source, and Path fill the right column, the wide Grain Process area becomes three compact timing/process/variation columns, and Voice or Routing spans both columns as the footer. LOAD and CLEAR are stacked beside every Lanes and Grains waveform, expanding the live source display by 64 pixels. The DSP publishes the active grains themselves over a darker waveform: faint fills accumulate with overlap, elapsed and remaining contours use distinct gray levels, contour thickness follows lane weight, luminance follows current windowed gain, and a white dark-haloed dot shows phase. Matching event rings animate in the read-head path scope. The Voice/Scan Rate/MIDI footer buttons use a lighter neutral fill. Sample Grains 2 adds Preserve Origins, Mono Sum, Left, Right, Mid, and Side interpretation, linked or independent stereo grain trajectories, and per-grain Mono Spread; its MIDI voice selector is labelled Polyphony, and it neither publishes nor honors the 32-channel allocator controls. Amount, Regions, and the other sliders use the exact visible track for both hit-testing and continued dragging. Those operation names deliberately parallel Slicer's vocabulary, while remaining a distinct live grain scheduler rather than its slice-rearrangement Mutate engine. Sample Grains 32 either preserves a multichannel source field or explicitly folds and allocates each grain across a selected 2–32-channel destination width; its compact Routing tab uses the same categorical active-output control as Lanes 32.
- Adds **s3g Sample Player 2** and **s3g Sample Player 16**, with chromatic polyphonic playback, Rate and duration-preserving Stretch pitch modes, forward/reverse loop and ping-pong modes, host-tempo sync, filter and amplitude envelopes, direct waveform editing and zoom, active-note cursor flags, shared Project/Link/Embed source storage, and stereo or relationship-preserving 16-channel output.
- Adds **s3g Sample Doubles 2**, a stereo two-read-head instrument with independent deck transport and levels, linked control, velocity-sensitive drag, zero-crossing cues with audible pre-roll and retriggering, analyzed or manual sample tempo, beat-based offsets and phase steps, live Deck B phase and drift, three crossfader curves, presets, and direct Tracker/MIDI command and CC mappings.
- Adds **s3g Sample Wavesets 2** and **s3g Sample Wavesets 32**. Both turn analyzed crossing-cycle groups into chromatic mono, legato, or polyphonic voices with source and group scopes, cycle ordering, repetition and stride, and a set of real-time waveset transformations. Wavesets 32 adds a reusable trigger-time allocator for 2–32 active outputs, mono destinations or stereo pairs, and sequential, reverse, palindrome, random, and no-repeat random routing.
- Revises **s3g Sample Slicer 16** around the shared Sample-family file, waveform, project-media, MIDI-start-note, editor, mixer, mutation, and documentation conventions while preserving its fixed 16-channel routing. Version 0.9.0 adds explicit Collage, Sorter, Stutter, Shrink, and Doublets mutation operations: Sorter chooses loudness or duration, Stutter chooses slice heads or joined groups, Shrink chooses linear or exponential truncation/acceleration, and Doublets can expand time or print pitch-preserved pairs in the original source duration.
- Extends **s3g Tracker** with MIDI step recording, held-note editing, undo and project history, runtime pattern planning, clearer note activity, expanded Song and timing behavior, and a scripted REAPER acceptance workflow. These additions support the new Sample-family note, CC, retrigger, and routing workflows directly.
- Expands **Processor Stack** with Stack Score, host synchronization, and additional controlled random-thinning behavior, and adds updated MIDI handling to Ambi Encoder Membrane Kick.
- Adds shared eight-channel ring-output projection to Processor Fault, Processor Loop, Processor Multi Loop, and Processor No Input Mixer, with direct, quad-ring, and stereo-ring formats plus rotation. Existing saved No Input Mixer states migrate to the unchanged direct-output default.

## Reliability and release checks

- The canonical manifest freezes 129 bundles, including 127 non-NIM bundles, and packaging verifies all 135 runtime plug-in descriptors rather than inferring descriptor count from bundle count.
- The Release build registers 140 CTest cases and the standalone build registers 49 cases. The sequential non-NIM product/test gate covers 137 cases, with the sanitizer configuration deriving its inventory from the same current product set.
- All 128 non-NIM bundle identities participate in isolated CLAP validation. Their callback-allocation audits cover the complete manifest with zero realtime allocation operations; all nine strict realtime profiles pass and the tenth 96 kHz environmental profile completes as an allocation-free advisory measurement.
- Dedicated DSP, CLAP, state, GUI, output-allocation, and multichannel routing coverage accompanies the expanded Sample family.
- Sample Doubles, Sample Wavesets, and Sample Motion use persistent compositor-driven cursor trajectories on macOS so predictable playheads remain smooth when a host temporarily delays AppKit presentation after a parameter gesture. Routine meters and static feedback remain on the ordinary GUI refresh path.
- Sample Player, Sample Doubles, Sample Wavesets, Sample Motion, Sample Lanes, Sample Grains, and Sample Slicer now default new instances to Project storage: sources receive content-hashed names and are copied asynchronously into the exact containing REAPER project's media directory, registered for copy-media Save As operations, and referenced with small state. Reloading the same unchanged external source reuses its verified destination, and directly reloading a file already in project media reuses it in place instead of creating a nested hash-suffixed copy. Unsaved-project requests remain pending until the host supplies a project media path. Link retains the original location; Embed remains explicit and reports the decoded PCM state cost. Earlier Embed and path-only sessions migrate without changing their storage behavior.
- The shared voice-output allocator and ring-output mixdown are covered as independent DSP components as well as through the plug-ins that consume them. Callback-allocation, CLAP validation, sanitizer, and realtime gates continue to derive their product inventory from the release manifest.
- Documentation adds complete Sample Player, Sample Doubles, Sample Slicer, Sample Wavesets, Sample Motion, Sample Lanes, Sample Grains, and Sample Rings guides and current interface captures, reorganizes the Sample-family and CRCLTR navigation, and updates the Tracker, Processor Stack, multichannel-output, and No Input Mixer material.

## Installation

The packaged pre-release supports REAPER on Apple silicon (`arm64`) Macs. It is not notarized, so macOS requires one Gatekeeper approval for the installer. The installer writes only to the current user's Library and does not use `sudo`.

1. Quit REAPER and unzip the archive.
2. Double-click `Install s3g-dsp CLAPs.command`.
3. If macOS blocks it, click **OK**, open **System Settings > Privacy & Security**, and choose **Open Anyway**. Confirm **Open** and authenticate if asked. This option is available for about one hour after the blocked launch.
4. If prompted, allow Terminal to access the downloaded package, then wait for installation to finish.
5. Start REAPER and rescan CLAP plugins if they do not appear automatically.

The installer places the collection in `~/Library/Audio/Plug-Ins/CLAP/s3g-dsp/`. On upgrades, it moves identity-verified older s3g-dsp bundles—including copies in the former top-level CLAP location—to a timestamped backup. Other CLAP products are untouched.

After approval, the installer verifies each staged bundle, removes only `com.apple.quarantine`, and preserves other extended attributes. Approval applies to the installer, so REAPER should not present a separate Gatekeeper dialog for each plugin afterward.

Pass `--dry-run` from Terminal to preview the exact changes.
